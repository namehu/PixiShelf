# 浏览器隐私偏好

状态：`current`（实现契约；生产发布与不同真实设备的验收须单独记录）。

## 用户行为

首次进入需要确认的页面，提供“隐私模式进入”和“原始模式进入”；两者都表示已成年。默认不勾选“记住本次选择，30 天内不再询问”。登录、API、整个用户设置区豁免提示。

选择按浏览器同源共享：后台、浏览区和所有本站标签统一切换，包括关闭隐私时立即解除其他标签的遮蔽。退出、登录或更换账户不重置；不同浏览器配置、HTTP/HTTPS、域名/IP、端口相互独立。隐私继续仅遮蔽媒体与敏感只读文字，不阻止媒体加载、不改变复制、编辑、导出或阅读记录，也不替代鉴权。

未记忆时，刷新、整页跳转、恢复关闭的标签/窗口、同标签离站后返回视为继续访问。全部本站标签关闭后普通新开重新询问，允许 5 秒交接宽限。冻结的标签可能无法在 500 毫秒内响应，新标签可能再次询问；不保证精确识别所有浏览器的关页与恢复行为。

记忆固定为确认时刻加 30×24 小时，切换模式会更新记住的模式但不续期。到期和“取消记忆，下次访问重新询问”均只影响后续独立访问，当前访问及其新标签继续。重新选择记忆才开始新的 30 天。

桌面顶栏、手机“更多”弹窗、沉浸阅读、独立作品预览和两类全屏预览提供同一开关。手机底部导航保留四项，隐私开关位于“更多”的工具区。开关直接切换，旁边箭头打开浏览器偏好面板，展示模式、到期时间及记住/取消动作。关闭模式不再追加成年确认。

## 状态与首屏

### URL 强制进入

- `/artworks?entry=direct` 强制选择原始模式；`?entry=privacy` 强制选择隐私模式。已有查询参数时使用 `&entry=direct`。
- 参数等同于预先作出进入选择，无需再点内容提示；优先于本标签恢复、其他标签选择和 30 天记忆，并同步到同源其他标签。后续手动选择或另一链接的选择仍按最后写入生效。
- 不自动创建记忆；已有未过期记忆更新模式但保持原到期时间。没有有效记忆时只影响本次访问。
- 登录仍然必需，未登录页面跳转保留原查询参数。登录后在解除首屏遮挡前消费参数，从地址栏移除 `entry`，保留其他参数、hash 和历史状态；刷新不反复强制切换。同路径查询参数导航也支持。
- 仅接受单个、大小写精确的 `direct` / `privacy`；空值、未知值和重复参数不生效。存储不可用时仍允许当前页面进入并沿用存储错误提示。
- 用于开发或 computer use 时，应在入口 URL 明确指定所需模式，无需由自动化脚本直接写内部存储键。带参链接会改变其他本站标签的视觉模式，包括解除遮蔽；它不授予登录或 API 权限。

### 浏览器状态

- 独立 Zustand store 保存初始化、待选择、隐私、原始状态；persist 只保存经 Zod 校验的长期 `{ mode, expiresAt }`，不携带账户或认证数据。
- sessionStorage 保存当前标签的访问标识和选择；BroadcastChannel 发现活跃标签，storage 事件提供兼容传输。收到变更通知后读取最新共享快照，不以晚到消息覆盖最新决定。
- 新标签先等待活跃标签回复，最多 500 毫秒；没有回复时读取未过期记忆，再读取有效交接记录，否则询问。已有标签继续其访问并核对共享的最新选择。
- localStorage 访问快照用于同步，不单独证明访问存活；pagehide 尽力写入 5 秒交接记录，不依赖 unload 清理或心跳引用计数。普通 HTTP 局域网不依赖 Web Locks。
- 服务端不知道本地选择，默认启用媒体遮蔽，并为需提示的页面设置不透明遮挡和 inert。浏览器确定模式后，先同步根节点隐私属性，再释放遮挡；初始化期间不提前显示选择弹窗。
- 损坏记录按无有效值处理。存储拒绝或配额错误不阻止当前页面选择，但提示无法保证刷新或下次访问时记忆。

## 旧版本与恢复

停止读取及写入账户 `media_privacy_mode`，不把旧值转换为长期记忆。升级后浏览器首次访问重新选择；通用设置表中的历史行原样保留，不需要 Prisma 迁移、批量删除或数据恢复操作。回退应用代码时旧账户设置仍在；新浏览器记录由带版本的独立键保存，不会修改旧账户值。

## 验收

自动测试覆盖状态机、两个同源标签、无 BroadcastChannel 的 storage 传输、晚到通知、并发选择、刷新恢复、交接过期、30 天固定到期、访问跨越到期、取消记忆、存储异常、SSR 遮挡、路由豁免与账户切换。

URL 入口回归另覆盖两种强制模式、查询参数消费、同路径导航、重复或非法参数、登录跳转、跨标签发现期间覆盖，以及已有记忆不续期。

真实浏览器另行验证后台打开详情的新标签、刷新/硬跳转、跨标签开关、关闭全部标签超过 5 秒再打开、恢复标签、同标签返回、未确认期间无敏感图文闪现，以及桌面/手机/HTTP 局域网与全屏面板层级。jsdom 测试不能替代这些浏览器生命周期和真实设备验证。
