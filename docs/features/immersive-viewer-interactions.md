# 沉浸浏览交互

本规格仅适用于 `/viewer`，不改变作品详情及其他预览入口。浏览器实测范围见[独立验证记录](../records/features/immersive-viewer-interactions.md)；生产发布未核验。

## 筛选记忆

点击「应用筛选」后，在本浏览器的 `pixishelf-viewer-settings` 保存关键词、媒体类型、排序、艺术家、标签、创建类型、视频音频、阅读状态、两组日期范围及最多媒体数。关闭未应用的面板不更新偏好；「清空筛选」或重置后应用会保存清空结果。从普通导航新进入时恢复最后应用的条件，随机排序重新生成种子，从首项开始。

点击作品标题、艺术家等链接离开后，通过返回回到同一条浏览历史时，恢复原作品及作品内的媒体位置，包括已加载的后续页。随机种子和列表属于该历史条目，返回不重新筛选；列表缓存保留在当前页面会话内，位置不写入浏览器偏好。筛选条件或账户变化时重置位置，新导航入口不复用旧列表。

URL 含任一沉浸浏览查询参数时，以 URL 查询为准，不叠加保存的关键词、阅读状态等条件；未指定的媒体类型和最多媒体数继续沿用原有浏览器偏好。作者／标签入口和带筛选链接只影响本次浏览，主动应用后才更新记忆。`entry=direct` 等非筛选参数不阻止恢复。偏好仍属于同源浏览器，不进行账户同步。

旧缓存只有媒体类型和最多媒体数时继续兼容；新增筛选快照通过已有 Zod 查询校验，不合法时忽略该快照。无数据库、媒体或 API 变更；回退前端代码即可恢复旧行为，旧版本忽略新增快照，后续保存可能移除它。

## 浮层与播放

单击图片、动图、视频或媒体区域留白，统一显示／隐藏顶部工具、作品信息与操作；视频播放控件始终保留，图片与动图隐藏信息后保留底部进度。为保留双击手势，单击在释放指针后等待 300 毫秒；移动鼠标和悬停不改变显隐。顶部工具与原有图片计数短暂淡入淡出，减少动态效果设置下取消过渡。必要的错误、加载和兼容播放提示不属于可隐藏浏览控件。

视频由画面中部双击、独立按钮或空格键播放／暂停。双击分区沿用媒体交互区域宽度，中间 60% 控制播放，左右各 20% 快退／快进；鼠标、触屏与笔一致，包含媒体留白区域。双击不改变浮层显隐，图片与动图双击不执行操作；作品喜欢通过按钮操作，单击喜欢／取消、长按选档，并可从更多菜单打开“作品评分”；详见[作品评分](./artwork-rating.md)。画面双击不触发评分或飘心动画。WebP、GIF 使用独立播放按钮，画面本身不触发播放；隐藏时移除按钮，播放器实例与播放状态保持。恢复界面后可继续操作。更多操作不提供“隐藏界面”入口，显隐仍由单击画面或键盘控制，不显示中央清屏提示。

底部信息采用紧凑摘要：作者头像、名称与日期一行，标题一行，喜欢和更多操作并排放在摘要右侧，按钮保留 44px 点击区域。描述最多展示一行，前三个标签以单行文本链接展示，其余标签由标签抽屉承载。长标题、描述和标签截断显示；完整内容可进入作品详情，多位创作者可从更多操作访问。底部留白适配手机安全区域，视频控制区仍保留在摘要上方。

| 输入                         | 行为                         |
| ---------------------------- | ---------------------------- |
| 单击画面                     | 切换浮层                     |
| 双击视频中部                 | 播放／暂停，不改变浮层       |
| 双击图片、动图               | 无操作                       |
| 双击视频左右两侧             | 按现有偏好快退／快进         |
| 横向／纵向滑动               | 切换媒体／作品，不切换浮层   |
| 触摸或笔长按播放中的视频     | 临时倍速；松开或取消恢复原速 |
| 触摸或笔长按图片、暂停的视频 | 打开更多操作                 |
| C / Esc                      | 切换浮层／恢复显示           |
| 视频空格键                   | 播放／暂停，不改变浮层       |

### 隐藏界面的底部进度

隐藏作品信息后，视频在底部保留完整的两行控制区：第一行是可拖动的时间进度条；第二行是播放／暂停、当前时间／总时长、声音、倍速，以及有数据时的视频导航入口。未知时长显示 `--:--` 并禁用定位，不影响其他控制；无音轨时声音按钮禁用。图片与动图多张时沿用完整界面的分段横条：每张一段，已到达的段点亮，隐藏前后样式和底部位置一致。隐藏时横条可拖动切图，不显示圆形滑块、独立计数或底部背景；单张保持画面干净。视频不增加多视频位置栏，底部沿用深色渐变与浅色轨道；恢复作品信息不重复创建播放控件。

图片拖动仅预览目标分段，松手或键盘提交后才切换媒体与阅读观察位置。视频复用原有拖动逻辑，显隐不重建媒体，不改变播放状态、倍速和声音。底部操作不触发显隐、双击、长按或横纵切换；两层 Swiper 均排除控件区域。隐藏的其他操作仍退出焦点顺序和可访问性树，底部进度保持可访问。

拖动期间阻止自动切项，提交后从当前媒体沿用自动浏览状态，不能解除用户或面板等原因造成的暂停。取消、失焦、后台切换、切媒体、切作品、显隐或打开面板时清理预览，后续残留移动与释放不提交旧目标。清屏功能不是浏览器原生全屏。

## 视频倍速

视频画面缩放由[视频画面显示](./video-display.md)统一定义；隐藏信息后仍保留缩放入口，切换媒体恢复完整画面。

视频底部控件显示当前倍速，点击按 1× → 1.25× → 1.5× → 2× → 3× → 1× 固定循环切换，默认 1×，不打开菜单。仅在本次 viewer 页面访问内记忆，跨横向媒体、纵向作品和筛选重挂载沿用；退出或刷新恢复 1×。不写入浏览器偏好或账户，不影响详情播放器和动图。

选择立即更新视频速率，不重启播放、不跳进度、不改变播放／暂停或声音状态；进度及章节保持原视频时间。长按临时速率取所选倍速与长按配置的较大值，松开、取消或切换媒体后恢复所选倍速，临时加速不修改选择。

倍速按钮支持鼠标、触屏与键盘，保留至少 44px 点击区域。操作不触发底层媒体手势、不暂停自动浏览，也不解除用户、面板、后台或播放失败造成的暂停。

## 自动浏览

仅 `/viewer` 提供跨作品自动浏览，每次进入默认关闭。从「更多」菜单主动开始，按当前位置先横向浏览本作品剩余媒体，再进入下一部作品第一项；保持当前 feed 的排序与筛选，到末尾显示「已浏览全部作品」，不循环。手动返回媒体沿用会话内视频位置；自动进入后续媒体从头播放。

| 媒体               | 前进条件                                             |
| ------------------ | ---------------------------------------------------- |
| 静态图、未识别动画 | 当前图加载成功且翻页动画结束后停留指定时间           |
| 视频               | 关闭循环，真正播放结束后前进；开启时接着当前位置播放 |
| 已识别 WebP 动图   | 从头播放一轮，按播放器结束通知前进                   |
| GIF/APNG           | 展示动图，加载完成后按指定时间前进；不新增格式解析   |

APNG 自动展示使用现有鉴权媒体接口读取原图，绕过缩略图转换；原图加载完成才开始计时。GIF 同样等待动画原图就绪，不将海报加载当作开始。

图片停留默认 5 秒，更多菜单提供 3、5、10、15 秒，仅在本浏览器的 `pixishelf-viewer-settings` 保存该偏好。开启状态、暂停原因、媒体位置和待切换任务不持久化，不共用详情页轮播设置。菜单内部允许滚动，自动浏览不新增常驻按钮、不增加底部摘要高度。

打开更多、标签、章节、筛选等面板或切到后台时暂停自动浏览及视频/WebP 播放。关闭面板、回到前台、重试成功均不自行恢复；更多菜单的「继续自动浏览」先关闭菜单，待交互锁解除后恢复。视频原位续播，图片重新计满停留时间；WebP 流式路径保留同图进度，兼容回退重新播一轮。GIF/APNG 暂停只停止前进计时，不保证动画画面冻结。关闭自动浏览保留当前位置并恢复手动模式，不主动解除用户暂停。

手动横滑、竖滑或方向键换项会取消旧任务；运行中从新位置继续，已暂停则保持暂停。点赞、声音调整及清屏不停止自动浏览、不重置图片计时。手势或进度拖动期间不得自动切项；播放中拖到末尾，松手后前进，暂停时拖到末尾则等明确继续后前进。视频中部双击、播放按钮或空格键暂停时同时暂停自动浏览；再次单独播放视频不恢复自动前进。

到已加载列表末尾时保留当前画面等待下一页，成功后只推进一次。等待时手动换媒体会撤销原待切换任务。媒体或分页失败时暂停并提供重试；媒体额外提供「跳过并继续」，不将失败项伪造为已读。修改筛选、切换账户、离开页面结束本轮。重试、换项与卸载使旧回调失效；预加载媒体不能触发前进。

阅读采集继续使用现有规则，自动运行的观察标识为自动浏览；视频到 90% 只标记已读，不能触发前进。结束事件先发布最终播放观察，再切媒体，不等待阅读请求往返。没有服务端 API、数据库结构或迁移变更。

## 状态与边界

- 喜欢、评分及阅读状态更新遵循[本轮列表稳定性](./artwork-search-and-favorites.md#本轮列表稳定性)。作品与媒体使用稳定标识，原位状态更新不卸载播放器或重置横向位置；窗口聚焦及网络重连不自动重筛当前 feed。
- 显隐状态贯穿本次连续浏览，切图、切作品不重置；重新进入页面默认显示，不存入浏览器持久化设置。
- 浮层显隐不增加或回退浏览器历史。返回键正常返回上一页；视频章节面板继续使用自己的返回关闭规则。
- 链接、按钮、滑块、信息区域不触发画面手势；筛选、标签、更多操作及章节面板打开期间暂停底层手势、切图和快捷键。
- 面板锁定时显式停用 Swiper 的键盘与滚轮模块；关闭后恢复。抽屉接管焦点，非活动媒体不可聚焦，媒体容器禁止原生滚动，避免焦点跳转导致画面偏移。筛选结果更新时同步画面与手势的活动位置。
- 纵向和横向 Swiper 都将无原生控件的视频视为画面，即使视频已获得焦点也允许滑动；保留按钮、输入框和带原生控件视频的焦点保护。面板锁定还必须同步实例的 `allowTouchMove`，不能仅更新 React 属性。
- 输入框、可编辑内容和交互控件不处理画面快捷键；组合键和按键重复不触发显隐。隐藏控件退出焦点顺序和可访问性树；独立界面切换入口始终只在键盘聚焦后以文字显现，顶部不常驻眼睛图标，也不提供隐私模式切换。
- 媒体切换、指针取消、拖动和窗口失焦取消待识别单击。加载失败及准备加载时保留画面手势，重试按钮只负责重试；浏览结束画面仍可切换浮层。
- 无数据库或服务端 API 变更；浏览器偏好新增图片停留秒数，旧数据缺失或非法时使用 5 秒。回退前端代码即可恢复旧交互。
