# 沉浸浏览交互

本规格仅适用于 `/viewer`，不改变作品详情及其他预览入口。浏览器实测范围见文末验证记录；生产发布未核验。

## 浮层与播放

单击图片、动图、视频或媒体区域留白，统一显示／隐藏顶部工具、作品信息与操作、播放控件和图片进度。为保留双击手势，单击在释放指针后等待 300 毫秒；移动鼠标和悬停不改变显隐。浮层短暂淡入淡出，减少动态效果设置下取消过渡。必要的错误、加载和兼容播放提示不属于可隐藏浏览控件。

视频由独立按钮或空格键播放／暂停。WebP、GIF 使用独立播放按钮，画面本身不触发播放；隐藏时移除按钮，播放器实例与播放状态保持。恢复界面后可继续操作。更多操作中的“隐藏界面”保留为备用入口，不显示中央清屏提示。

底部信息采用紧凑摘要：作者头像、名称与日期一行，标题一行，喜欢和更多操作并排放在摘要右侧，按钮保留 44px 点击区域。描述最多展示一行，前三个标签以单行文本链接展示，其余标签由标签抽屉承载。长标题、描述和标签截断显示；完整内容可进入作品详情，多位创作者可从更多操作访问。底部留白适配手机安全区域，视频控制区仍保留在摘要上方。

| 输入 | 行为 |
| --- | --- |
| 单击画面 | 切换浮层 |
| 双击图片、动图或视频中部 | 点赞 |
| 双击视频左右两侧 | 按现有偏好快退／快进 |
| 横向／纵向滑动 | 切换媒体／作品，不切换浮层 |
| 触摸或笔长按播放中的视频 | 临时倍速；松开或取消恢复原速 |
| 触摸或笔长按图片、暂停的视频 | 打开更多操作 |
| C / Esc | 切换浮层／恢复显示 |
| 视频空格键 | 播放／暂停，不改变浮层 |

## 状态与边界

- 显隐状态贯穿本次连续浏览，切图、切作品不重置；重新进入页面默认显示，不存入浏览器持久化设置。
- 浮层显隐不增加或回退浏览器历史。返回键正常返回上一页；视频章节面板继续使用自己的返回关闭规则。
- 链接、按钮、滑块、信息区域不触发画面手势；筛选、标签、更多操作及章节面板打开期间暂停底层手势、切图和快捷键。
- 面板锁定时显式停用 Swiper 的键盘与滚轮模块；关闭后恢复。抽屉接管焦点，非活动媒体不可聚焦，媒体容器禁止原生滚动，避免焦点跳转导致画面偏移。筛选结果更新时同步画面与手势的活动位置。
- 纵向和横向 Swiper 都将无原生控件的视频视为画面，即使视频已获得焦点也允许滑动；保留按钮、输入框和带原生控件视频的焦点保护。面板锁定还必须同步实例的 `allowTouchMove`，不能仅更新 React 属性。
- 输入框、可编辑内容和交互控件不处理画面快捷键；组合键和按键重复不触发显隐。隐藏控件退出焦点顺序和可访问性树；独立界面切换入口始终只在键盘聚焦后以文字显现，顶部不常驻眼睛图标，也不提供隐私模式切换。
- 媒体切换、指针取消、拖动和窗口失焦取消待识别单击。加载失败及准备加载时保留画面手势，重试按钮只负责重试；浏览结束画面仍可切换浮层。
- 无数据库、API 或持久化结构变更。回退前端代码即可恢复旧交互。

2026-10-17 生产反馈修复：点击视频隐藏后不能上下滑动，恢复浮层仍不能滑动，而底部信息区可以滑动。根因为 Swiper 默认将已聚焦的 `video` 当作控件并提前退出拖动；显隐保留视频节点，也保留了焦点。此前 mock Swiper 的组件测试未覆盖该分支。本次两层 Swiper 均排除无原生控件视频，新增真实 Swiper + ImageSlide + 手势引擎集成测试；12 项鼠标／触摸指针、显隐、横向及单／多媒体纵向切换回归在旧焦点配置下全部失败，修复后通过。额外两项真实面板锁定回归发现 React 属性未同步实例 `allowTouchMove`，同步修复后 14 项全部通过。jsdom 仅补充布局尺寸和点击聚焦动作，不替换 Swiper。
