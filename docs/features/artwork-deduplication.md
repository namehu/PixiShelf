# 同艺术家作品去重

本文说明开发分支已实现的流程，不代表生产实例已部署。第三批发布候选在独立数据库、媒体根和端口验收，状态以[第三批记录](../records/artwork-deduplication-direct-delete-batch3-2026-10-24.md)为准；后端及故障边界证据见[第二批](../records/artwork-deduplication-direct-delete-batch2-2026-10-24.md)。原隔离、移动、恢复和到期删除方案已取消。

## 检查与审核

艺术家页“检查重复”进入 `/admin/duplicates?artistId=…`。用户主动开始后冻结该艺术家当前有效归属的活动作品；后来新增作品留待下次。同一艺术家只允许一个活动检测，暂停也占用该资格，离开页面不终止后台任务。

精确重复指全部登记原文件的 `(大小, SHA-256)` 排序多重集合相等，忽略文件名和顺序，保留重复次数。图片、动画、视频按原件字节比较；组合媒体包含全部登记物理原件。支持本地创建、Pixiv导入、本地导入、URL归档四来源及混合组，不做相似度、部分重叠或跨艺术家检测。

检测先核对文件属性，仅对数量和可靠大小清单匹配的候选读取内容。有效文件哈希持久化，普通检查可复用，完整检查对候选绕过缓存。缺失、不可读、零字节、读取中变化或根异常不能形成完整重复证据。正常无重复、局部未完成和整次失败分别展示，任务支持暂停、继续、取消和原范围重试。

页面分为“检查结果”和“删除记录”。结果按组分页，长组成员另分页；保留作品的选择和要删除哪些组的选择相互独立。唯一有手工整理记录的副本优先推荐保留，多份有整理记录时需要明确选择。跨页全选由服务器冻结完整范围，不能只处理浏览器已加载的作品。

## 预览与一次确认

“预览删除”创建新目的 `DIRECT_DELETE` 的后台准备操作。READY预览展示服务器冻结的保留者、副本和精确文件范围；文件条目区分保留文件与待删文件。共享路径、硬链接、符号链接、未知附件及未验证的归档历史原件阻断执行，不静默缩小确认范围。旧隔离预览只能查看，不能补签为新删除授权。

同一面板完成一次确认：说明永久删除不可恢复、整理记录不合并，并要求确认后果以及所选目录的外部同步和编辑持续停写。没有隔离、恢复、口令或第二次删除确认。实际授权绑定Session操作者、账户一致性参数、操作版本、冻结范围摘要和幂等键；浏览器不能提交或扩大文件路径清单。按钮是否可用由服务器返回的动作和当前能力决定。

标题、来源、创建时间和文件范围来自持久快照。个人评分、阅读、书签和喜欢只显示当前账户的实时记录，并明确执行前复核；已删除副本显示“已随副本删除”，不会将未保存的历史明细伪装为零。标签、系列、章节及派生记录随副本删除的影响需明确说明，但不虚构没有保存的历史细节。其他账户只显示必要保护资格，不公开其标记、数值、数量或时间。

提交期间禁重复操作，网络响应未知时查询并续看同一操作；原输入重放复用原幂等键，不新建删除任务。切换账户会清理选择、确认和待提交状态，旧账户的迟到响应不能更新新会话。

## 删除、停止与续行

Worker先同时认领保留者和副本、阻止应用内冲突写入，并确认相关执行实际退出。随后绕过缓存复核所选全部组；全部成功后才允许首个删除意图。App请求不遍历媒体或执行删除，系统仍使用既有三条执行通道。

仅逐项删除冻结清单中的文件，不移动文件、不删除整个艺术家目录，也不清理空目录。每步先持久化意图，再核验身份并删除、同步父目录，最后提交回执；数据库与文件系统之间不存在共同原子事务。所有文件回执完成后才删除副本业务记录，保留者不合并副本的私人整理信息。普通URL归档删除继续使用原回收流程，去重专用删除不进入回收站。

首个删除意图产生前可请求取消；之后只能“请求停止”，等待安全边界停下，已删除文件不可撤销。界面依据真实持久意图区分两者，不根据阶段名称猜测。部分失败或停止后，副本保持隐藏，清单和保护仍在；只允许复核保留者并继续原删除范围，不提供换保留者、扩围或恢复入口。

删除记录保留原范围、已删和待删数量、必要的脱敏原因；文件计数按文件去重，不因重试的多条回执重复计算。读取进程退出未确认时保留占用，不能把租约过期、任务失败或发送kill当作退出证明。

## 来源、权限与运维

可再次发现的来源保留独立墓碑，阻止重扫和旧任务重新发布已删作品。“允许重新导入”只解除选中的真实来源并推进重叠来源代次，允许未来的新输入；不恢复文件，不使旧任务有效。没有可发现来源的本地创建作品不显示伪造来源。

所有入口要求Session与expectedUserId一致；检测结果是共享管理事实，发起者是审计身份。DTO不返回绝对媒体路径、根身份、原始哈希、执行租约或其他账户私有明细。独立删除开关不由客户端或旧release stage授予。部署顺序、外部持续停写要求、部分失败处置与降级限制见[去重运维手册](../operations/runbooks/artwork-deduplication.md)。

性能沿用已有有界分页、单读取进程和让行机制，详见[检测契约](../design/artwork-deduplication/phase-2-contracts.md)。真实文件校验、持久意图和POSIX能力限制见[文件执行契约](../design/artwork-deduplication/file-execution-contracts.md)。合成数据测试不等于生产备份恢复演练，手机触控与安全区的真机检查单由最终验收记录维护。
