# 作品搜索与我的喜欢

本文维护喜欢集合的浏览规则与标签名称查找。评分与爱心的统一状态、操作及迁移见[作品评分与喜欢](./artwork-rating.md)，预设保存、应用及并发规则见[快捷筛选](./artwork-quick-filters.md)，候选及分页见[查询架构](../architecture/artwork-feed-query-performance.md)。不新增收藏夹、标签别名或来源实体合并。

## 本轮列表稳定性

作品列表与沉浸浏览在筛选条件不变的本轮浏览中，已加载条目的成员、顺序和当前位置保持稳定。喜欢、取消喜欢、评分及阅读进度只原位更新，不自动移除、插入或重排条目；“我的喜欢”和“只看未读”同样遵守。状态保存不取消首屏或下一页请求，窗口重新聚焦及网络重连也不触发本轮列表重筛。后续分页只追加候选，已加载页不随状态写入重新获取。

刷新、重新应用筛选或新进入列表时才获取新的候选；从作品详情返回已有阅读筛选列表时，继续沿用其本轮快照和滚动位置。此约束是客户端浏览稳定性，不承诺未加载候选的数据库快照。缓存及迟到响应仍按账户隔离。

## 喜欢等级与排除艺术家

- 共享筛选面板提供「喜欢／超爱／夯爆了」三个独立多选按钮，对应当前 Session 账户的 `ArtworkLike.level = 2 / 3 / 4`。精确匹配所选等级，多选取并集；全部不选表示不限评分，包含未评分和一般档。与关键词、标签、媒体、来源、阅读状态、日期及排序组合。
- 包含艺术家仍为单选；排除艺术家支持独立搜索、多选。只要作品的任一有效作者在排除集合中，整件作品就不显示，合作作品也一样。只约束当前查询，不设置全局屏蔽；包含与排除冲突正常返回空结果。
- 所有面板条件编辑草稿，点击应用后查询；清除恢复不限条件。URL、列表／沉浸 API 使用 `ratingLevels`、`excludeArtistIds`；边界统一验证、去重、排序。旧 `likedOnly=true` 链接、API 请求或预设兼容为三档全选；明确提供新等级字段时以其为准，包括空数组／空字符串。
- 快照保存排除艺术家的 ID 和显示名；URL 的 `excludeArtistLabels` 仅供显示。查询使用现有有效作者关系，已失效的预设引用按[快捷筛选规则](./artwork-quick-filters.md)处理。
- 选中等级的非随机列表使用 keyset 游标，随机列表使用随机游标。游标、缓存和滚动恢复键包含新增条件及账户；改变条件不能复用旧游标。评分改变仍遵循本轮稳定性：原位更新，刷新或重新应用筛选时才重新确定候选。
- 身份来自服务端 Session。`expectedUserId` 仅拒绝账户切换后的过期查询和评分写入，不授予其他账户的访问能力。[权限边界](../security/access-control.md)

## 艺术家详情与沉浸范围

艺术家详情提供关键词、标签建议和完整共享筛选面板。路由中的艺术家是固定范围，不被关键词建议、清除条件或预设替换。排除当前艺术家允许应用，空结果说明当前艺术家已被排除。专属快捷筛选只保存附加条件，按账户与艺术家隔离。

艺术家详情进入沉浸浏览时传递 `scopeArtistId`，与全局列表仅选中某位艺术家而产生的 `source=artist` 区分。带范围标记时修改或清空筛选始终保留该艺术家，且不写入全局沉浸偏好；全局入口仍可切换或清除艺术家。沉浸只继承条件，不增加预设管理；正常返回保留详情页 URL 与状态，无站内历史则回到对应艺术家详情。范围标记是浏览上下文，不是权限边界。

## 标签原名与译名

- 支持标签选择的作品列表／筛选搜索框中，输入 `#` 前缀进入标签建议，例如 `#风景`；前缀不参与名称匹配，清除前缀恢复普通模式。普通作品关键词保持既有职责；仅接收关键词的其他搜索框不把 `#` 解释为标签模式。
- 建议支持 `name`、`name_zh`、`name_en` 的不区分大小写包含匹配，非空单字可查询，结果数量有界。一个标签多个名称命中只返回一次，显示去重后的原名及译名。
- 选择建议按稳定标签 ID 应用条件，不把译名当成新标签或作品关键词。标签输入在选中前仅作为本地查询，不写入作品关键词草稿。Enter 仅在有高亮建议时选择；空白、仅 `#` 或没有选中结果时，不隐式提交作品关键词或清除原有筛选。
- 标签管理复用三字段包含匹配。标签列表／选择器保留 PostgreSQL 全文索引、分词前缀匹配、相关度及分页；查询清理保留 Unicode 字母和数字，原名中的假名等字符不再被删除。

支持相同名称字段不表示各入口有相同排序或任意子串匹配：建议／管理采用包含匹配，列表仍为全文搜索。此变更不新增搜索引擎、不合并同义标签、不改变来源标签或人工覆盖。
