# 作品快捷筛选

## 用户行为

作品列表与艺术家详情的筛选抽屉提供「筛选条件 / 快捷筛选」两个 Tab，标题、Tab 和底部操作固定，中部滚动。阅读状态直接显示在常用条件区，单选「全部 / 未读 / 阅读中 / 已读完」，沿用账户阅读进度的三态定义：零已读且没有有效观看访问为未读；部分完成或已开始观看但未完成的视频为阅读中；非空作品全部逻辑媒体完成为已读完。定义由[阅读规格](./artwork-reading.md)维护，预设不另建计数规则。

条件面板编辑草稿，切换 Tab 保留草稿，关闭普通筛选不应用。保存快捷筛选保存当前草稿但不改变作品列表，名称去除首尾空格后为 1–40 字，同账户、同作用域区分大小写且禁止完全同名。可以保存无过滤条件的「全部作品」。每账户、每作用域最多 100 条。全局新建时有导航空位默认加入导航；导航已满仍可保存，不能自动替换已有项目。艺术家专属筛选不提供导航管理。

保存内容包括关键词、媒体类型、排序、艺术家、排除艺术家（含显示名）、喜欢等级、标签、创建类型、视频音频、阅读状态、作品原始日期和入库日期。日期保存明确起止值，不随时间滚动。随机排序只保存排序方式，每次应用重新生成种子，同次浏览分页沿用该种子。随机实现采用固定乱序的随机起点，走索引并在末尾回绕一次；不同种子可能保留相似邻接关系，不承诺独立全量洗牌。分页游标、滚动位置和导航管理参数不进入快照。

快捷列表分为「导航中 · n/10」及按创建时间倒序的「其他快捷筛选」。点击整行直接应用，整体替换旧条件，重新开始列表并回到顶部。应用后的查询独立于预设，之后修改或删除预设不会追溯改变当前列表。包含或排除的艺术家、标签已经删除的预设不可直接应用，需在编辑中显式移除或重新选择，不静默扩大查询。

每行菜单可编辑、重命名、加入或移出导航、删除。删除需确认。编辑复用条件表单，进入明确的编辑模式，保存后返回快捷列表；普通草稿保留。存在未保存编辑时，关闭或取消需确认。保存失败保留草稿。导航最多 10 项，可从专用手柄拖动，或用菜单上移、下移；不自动按最近使用重排。

预设保存 `ratingLevels` 精确等级集合；旧预设的 `likedOnly=true` 兼容为三档全选，明确提供新字段时以其为准。应用时使用当前会话账户评分，不保存或接受其他账户身份。条件的显示、查询及账户边界见[作品搜索与我的喜欢](./artwork-search-and-favorites.md)。

## 导航与可访问性

- 桌面「作品」保留链接，独立箭头立即打开快捷菜单，鼠标悬浮 1000ms 也可打开；进入菜单保持打开，离开触发区和菜单 200ms 后关闭。
- 手机底部「作品」使用按钮承载手势，避免带地址链接触发 Android 原生链接菜单；短按进入列表，长按 500ms 打开菜单；移动超过 10px、多指、touchcancel 中止，长按释放后的兼容 click 被抑制。普通入口仍可从筛选面板进入快捷 Tab。
- 菜单最多展示 10 条，受可用视口高度约束可滚动，末尾有「管理快捷筛选」；空状态保留管理入口。键盘、Escape 和焦点恢复由现有菜单组件配合对应入口处理。
- 名称、摘要和失效引用提示使用全局隐私文本标记；输入框仍为可编辑真实内容。不查询每个预设的命中数。
- 管理入口在作品列表和艺术家详情启用；艺术家详情只管理当前账户、当前艺术家的预设，不出现在其他艺术家、全局作品列表或「作品」长按菜单。沉浸浏览只继承条件，不提供预设管理。
- 艺术家预设仅保存附加条件，固定作者由作用域确定；应用或清除不改变该页艺术家，不自动应用已保存预设。保存、编辑、重命名、删除和冲突处理沿用共享组件。

## 数据和接口

无需数据库迁移。沿用 `UserSetting` 的账户外键和 `(userId,key)` 唯一约束，每条预设一个 `artwork_quick_filter:<uuid>` JSON 记录；`artwork_quick_filter:navigation` 保存有序 ID 数组及独立修改版本。艺术家预设存于 `artwork_quick_filter:artist:<artistId>:<uuid>`，全局读取明确排除艺术家子空间。预设包含结构版本 1、修改版本、名称、查询快照及创建时间。

`artworkQuickFilter.list/create/update/delete/setNavigation` 均使用会话认证；`expectedUserId` 必须与会话一致，仅作账户切换前置条件，不是身份来源。通用设置写入拒绝整个保留前缀，通用设置读取排除它。专用 schema 验证名称、条件、日期、ID 和导航数组。API 的 `scope` 为 `{kind:"global"}` 或 `{kind:"artist",artistId}`，省略时保持全局行为。增删改查均按作用域定位，艺术家作用域禁止固定作者进入快照、禁止 pin 或 setNavigation；全局导航也不能引用艺术家预设。

每次修改在事务内锁定当前 `UserBA` 行，串行检查当前作用域数量、名称与导航约束；读取后的修改在同一锁范围提交。单条预设更新、删除检查自己的 revision，导航整体更新检查独立 revision。不同预设编辑不互相覆盖，同条过期写入、删除竞争或过期导航写返回冲突。创建时导航满则只保存预设；删除固定项与移出导航原子完成。

导航和抽屉复用按账户及作用域分隔的 TanStack Query 缓存，打开、窗口重新获得焦点及写入后刷新。账户或艺术家切换重置草稿及编辑界面，异步响应不更新其他账户或作用域的界面；服务端再次核对账户。失败状态支持刷新，不自动覆盖远端新版本。

## 验证与恢复

聚焦测试覆盖快照往返、特殊标签文本、随机种子、日期、保留前缀、认证、草稿保存和编辑、悬浮计时与移动手势。隔离 PostgreSQL 测试覆盖不同条目编辑、同条冲突、重名竞争、总量及导航上限、账户隔离和失效引用。测试入口：`tests/integration/artwork-quick-filter.postgres.test.ts`；必须提供专用本机 `pixishelf_quick_filter_test` 数据库以及 `QUICK_FILTER_TEST_DATABASE=1`，否则跳过。

临时测试库使用正式 `db:deploy`，禁止 `db:push`；不会操作生产收藏。用户预设属于数据库备份内容，沿用备份恢复基线。回退应用版本必须理解新的艺术家键空间及精确等级字段，避免旧全局读取混入艺术家预设或扩大等级查询；不需要反向迁移，也不删除新记录。新预设数据需要恢复时使用数据库备份，不涉及媒体文件变更。页面和专用 API 应一起发布或回退。

艺术家独立作用域的验证与限制见[增强筛选验收](../records/features/artwork-filters-2026-10-30.md)，早期全局预设行为见[历史记录](../records/features/artwork-quick-filters.md)。
