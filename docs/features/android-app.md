# Android 沉浸阅读验证版

本版用于判断原生阅读是否值得继续投入。Flutter 独立包承载作品详情、沉浸浏览和轻量阅读整理；Next.js 继续拥有领域数据与业务规则。[决策](../adr/0009-android-flutter-reader.md)、[安全边界](../security/access-control.md#移动客户端接口)、[包级运行说明](../../packages/pixishelf-app/README.md)分别负责选型、认证与开发步骤。`current` 不代表生产已部署或真机已验收。

## 使用流程

登录页、内容确认和浏览设置采用浅色界面，沿用网页版蓝色主操作；全屏媒体与其浮层使用独立深色主题。登录表单支持密码显示切换、系统字体缩放和键盘弹出后滚动。

输入已有实例的 HTTPS 根地址、用户名和密码。默认仅接受有效系统证书；不接受普通 HTTP、URL 凭据或带路径的实例地址。显式 USB 调试构建的回环地址例外见[安全边界](../security/access-control.md#移动客户端接口)，不进入 Release 构建。没有注册、首次管理员初始化或服务器自动发现。登录后确认内容提示，可选择隐私遮蔽或原始显示，并可记住 30 天；切换显示模式不会延长期限。

登录与内容确认后进入「作品」图库首页，沿用 H5 的搜索／筛选工具栏、3:4 封面网格、作品标题与艺术家信息。支持关键词、H5 的 11 种排序、媒体类型、阅读状态和「只看我的喜欢」；默认按原始时间倒序。详情和沉浸页的创作者／标签可进入相应筛选列表。筛选使用草稿，点击「应用筛选」才更新列表，关闭不应用；已应用条件可逐个移除，按服务器与账户保存。列表下拉刷新、接近底部加载下一页，失败保留已有条目并提供重试。高级日期／音轨／创建方式条件、建议搜索和快捷筛选管理仍未完整迁移。

按 Android 对比版的明确要求，点击封面直接进入可上下切换作品的沉浸阅读器，卡片标题进入作品详情；简约模式可在沉浸页点击作品标题进入详情。「沉浸浏览」工具栏和底栏入口也进入跨作品阅读器。这一入口取舍不同于当前 H5 默认的封面进入详情。阅读器继承本轮已加载作品顺序、筛选、随机种子和分页游标；返回保留图库的筛选及滚动位置，已确认阅读状态原位更新，不重筛或移除条目。「继续上次浏览」位于更多设置，使用该账户本机保存的位置及筛选，作品已删除时清除失效位置并重新浏览。封面与选图缩略图都是静态预览，不自动播放、不产生阅读观察。

列表沿用 H5 白底与文字配色、56dp 单行搜索工具栏、3:4 封面与卡片文字规格；读取同账户 `artwork_display_mode`，卡片模式间距 12dp，简约模式间距 2dp、无圆角和标题。偏好标签与视频大小角标由服务端复用 H5 投影。底栏仅提供已有的作品、沉浸浏览、更多三个入口，没有未实现的首页按钮。沉浸页使用顶部两枚圆形按钮、右上页码和底部紧凑作者／标题／横排操作；设置收进更多菜单。

## 作品详情

详情沿用 H5 的浅色纵向结构：标题、创作者、标签、阅读进度在前，有序媒体居中，描述、来源、系列前后篇和作者邻作在后。创作者邻作支持来源时间／入库时间与前后分页；原站链接由服务端校验，交给外部浏览器打开且不携带移动 Token。完整管理、媒体编辑和顺序校对继续留在网页。

完整模式默认先显示 10 项，偏好范围 1–100；总数不超过 `N + floor(N × 25%)` 时自然显示全部，否则提供展开／收起；堆叠模式展示分组后的完整候选序列。列表按需构建，只有可见项解码；未加载和离屏内容不产生阅读。页码入口支持任意页跳转，保持原始序号，回顶部不重建作品。

完整模式的媒体按原比例满宽连续拼接，不在每图底部添加序号栏、状态栏或间距；序号留在选图与长按操作面板。单图书签、喜欢、标为已读和原图入口由长按图片打开，堆叠模式保留分组导航。

普通进入停在顶部；已有第 2 项以后继续位置时提示「从头开始／跳转」，8 秒后关闭，不自动跳走。显式媒体位置优先定位，定位过程中不把首图误记为已读。点图进入当前作品的适配预览，继承当前候选序列，退出后按最后媒体 ID 回定位。它与可上下切作品的独立沉浸页分开。

「只看未读」冻结开启时的候选 ID；正常阅读或手动标记不立即移走当前项。只有「刷新未读」重新取权威状态并更新集合；空态可返回全部。「标记全部已读」以及加载失败项的单张补记复用现有正向已读操作，不增加真实访问次数、时间或继续位置。

作品评分为未评分／一般／喜欢／超爱／夯爆了（null、1–4），2 及以上与作品爱心共用状态。单图书签和单图喜欢是独立标记，长按媒体打开操作；写入串行化且按账户隔离。展开面板本身不写入，失败保留权威状态并提示。

完整／堆叠切换使用服务端共享算法生成的分组，保留当前媒体；连续静态图分组，动画、视频和多成员逻辑项为边界。组内左右切换，外层纵向阅读。堆叠观察携带规则版本、完整索引指纹和组 ID，服务端重新核验；普通预览不继承堆叠授予。自动滚动／自动翻阅需主动开始，操作、弹层、后台和错误停止，恢复前需要用户明确继续。

## 沉浸浏览

上下滑切作品，左右滑切作品内媒体；手势先锁方向，屏幕两侧留出系统返回区域。图片支持双指缩放、拖动和双击 2.5 倍，缩放期间禁止翻页；翻页使用有限的旧画面保留与滑动过渡，双击缩放有连续动画，系统关闭动画时减少动效。单击切换浮层与 Android 沉浸系统栏；返回依次恢复缩放、显示浮层、退出界面。紧凑信息区提供作者、日期、标题、描述及标签；标题可进详情，返回保留当前作品和媒体。阅读器复用图库的筛选面板，新筛选开启新一轮浏览。 Android 系统栏使用原生 WindowInsetsControllerCompat 控制并保留 edge-to-edge 布局，依据 [Android 沉浸模式文档](https://developer.android.com/develop/ui/views/layout/immersive)，避免依赖被新版系统限制的旧全屏标志。

点击阅读器页码打开「作品内选图」底部抽屉，定位当前项；每项有序号、当前项边框、已读提示及视频／动图标识。按可见范围请求对应媒体页和 512px 静态缩略图，支持跨页选中。打开期间暂停底层媒体及阅读观察；取消不换图，点击后直接跳到目标并恢复正常阅读。隐私遮蔽覆盖列表与抽屉，返回键先关闭抽屉。缩略图不可用时保留占位与选中入口，不请求播放原件补封面。

喜欢复用作品评分：2 及以上显示已喜欢，点喜欢设为 2，取消喜欢清除评分。快速连点按最后一次意图串行提交，失败重新读取权威状态；不是独立点赞表。阅读语义继续由[阅读服务](./artwork-reading.md)决定，媒体预加载、失败、被覆盖和后台都不产生新观察。

爱心长按或更多菜单打开评分；更多菜单还提供当前图片喜欢。底部分段进度在隐藏信息后仍可用，拖动只预览目标，释放才切换，取消不提交。自动浏览提供 3／5／10／15 秒间隔，默认 5 秒；成功显示且转场结束后才计时，先读当前作品剩余媒体再进入下一作品，列表末尾结束。视频等实际结束，动态 WebP 可用时等一轮；GIF／APNG 采用间隔。手动操作、缩放、面板、后台及错误暂停，关闭面板或回前台不自动继续；旧计时与迟到回调不能切走新媒体。

## 图片、动图与视频

| 媒体            | 行为与边界                                                                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 静态图          | 初始按需请求受保护的 2048px WebP 预览；缩放后取原图，解码输出最多 4096px、1600 万像素。保持比例完整显示。                                                    |
| GIF / 动态 WebP | 原始字节交给 Flutter codec，播放当前媒体，支持暂停，后台或弹层覆盖暂停。                                                                                     |
| APNG            | 读取原始 PNG/APNG，在独立 isolate 增量解码，按 source/over 混合与 background/previous 处置合成；保留当前画布及必要快照，不解码保存全部帧。缩放不会重启动画。 |
| 视频            | Android 原生播放器流式读取，默认静音自动播放。沉浸页隐藏信息后仍保留播放、进度、音量、倍速与适配缩放；手动浏览循环，自动浏览等结束再推进，并在当前阅读会话内保存播放位置。详情内嵌视频不循环。 |

视频原件通过新接口提供单段 Range/206/416；支持格式取决于设备解码器，不承诺所有容器／编码可播。当前没有服务器转码。APNG 输入限制 32MiB、画布 800 万像素、帧数 10000，输出长边最多 2048px；超限或损坏显示可重试错误，不静默变为静态图。普通图片原件下载限制 64MiB，视频流不套用图片大小限制。

沉浸视频中部双击播放／暂停，两侧双击快退／快进；播放时长按临时加速，松手恢复所选倍速；暂停时长按打开操作。倍速在当前阅读会话内保留，画面缩放切媒体重置。存在已登记章节或仍匹配原视频的已发布关键帧时提供时间点导航并定位播放；本版尚未显示关键帧派生缩略图。普通导航获取失败不阻断原视频播放，认证失效仍按账户错误处理。

沉浸页只播放当前媒体，切换释放旧 codec、isolate 或视频播放器；详情可同时展示多张可见静态图，但只激活当前项的动图／视频，离屏项释放媒体。后台、弹层覆盖时暂停；普通手动浏览在未被用户暂停时恢复播放，已暂停的自动浏览仍需明确继续。图片与缩略图下载合计最多并发 2，压缩字节 LRU 预算 32MiB；沉浸页只预取相邻静态图与下一作品的一张静态预览，不预取播放动图或视频。原件和缓存只在内存，不实现离线图库。

Debug 仅用于功能联调；真机操作流畅度使用 Profile／Release 验证。USB Profile 可显式启用与 Debug 相同的回环联调地址，Release 继续只接 HTTPS。可选帧耗时采样与重跑命令见[包说明](../../packages/pixishelf-app/README.md#usb-本地联调)。

## 位置、并发和失败

本地位置按服务器与账户隔离，保存作品 ID、媒体 ID、搜索及排序，不存任意页偏移。重新进入先恢复作品和逻辑媒体；媒体已移除时使用服务端继续位置，作品已不存在时开始新浏览。随机列表新会话使用新种子，恢复作品去重合入新列表。

每次会话或选中媒体变更使旧回调失效。阅读只在媒体已实际显示且满足可见条件后开始；视频必须有实际播放位置，完成条件仍为服务端 90%。每 3 秒批量发送，图片每 60 秒心跳；视频仅使用播放观察。沉浸页上报临时失败最多短期内存重试两次，过期／版本冲突丢弃并提示；详情上报失败提示用户，该批次不自动重放。两者均不持久化离线写队列。切换账户销毁旧客户端和内存缓存。

401／账户不一致回到登录，409 提示重载，媒体缺失、无法解码、网络失败均提供重试。退出尝试撤销服务端会话并清除本机安全存储；网络中断时只能保证本机退出，远端会话遵循服务端到期和撤销规则。

## 最小接口与影响范围

新增 `/api/mobile/v1` 的 session、feed、reader、media page、媒体读取、reading、rating，以及详情、作者邻作、单图标记、手动已读和视频导航。JSON 契约见 [OpenAPI](../api/mobile-v1.openapi.json)；领域字段以现有 DTO 为准。API 仅作输入校验、认证及 DTO 适配，复用查询、阅读、评分和媒体标记服务。媒体使用登记 ID 和版本，不暴露文件路径，不借用 ImgProxy 公网入口。

原有网页路由、组件、tRPC、Server Actions、Cookie 登录保持既有入口。共享代码仅在认证工厂增加可选移动实例，以及 proxy 增加精确移动路径分支；没有数据库迁移、Worker 改动或部署配置修改。独立 Flutter 包不加入 pnpm 构建链。回退此功能可退回服务端版本并卸载 APK，不需要回滚数据库结构；通过 App 已产生的合法阅读／评分／单图标记与网页同等保留。

## 验收与后续判断

必须覆盖：无／错凭证零领域写入、跨账户拒绝、媒体版本与路径边界、图片手势互斥、APNG 帧变化与暂停、视频播放／拖动／覆盖暂停、预加载不记读、喜欢失败恢复、旧账户迟到响应隔离。初版自动化和模拟器证据见[验证记录](../records/features/android-app-2026-10-28.md)；图库与选图迭代见[图库验证记录](../records/features/android-gallery-2026-10-28.md)；详情与沉浸对齐见[核心页面迁移记录](../records/features/android-core-parity-2026-10-28.md)。

继续投入前，用真实 Android 手机和自有测试图库比较网页：连续浏览 15 分钟的全屏舒适度、切图响应、误翻页次数、放大清晰度、视频／APNG 发热与内存、后台恢复和服务端进度一致性。没有完成真机与真实 HTTPS 登录联调前，本版只作为验证构建，不认定可正式发布。

本轮不做离线下载、复杂管理、分享收件、iOS 或鸿蒙。界面与交互改善不等于已经证明性能优于 H5；USB Debug 构建只用于功能验证，性能、发热与长时间稳定性需在优化构建和同等网络条件下另测。
