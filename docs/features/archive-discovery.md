# 来源发现

发现来源建立远端候选目录，由管理员决定哪些进入[归档收件箱](./archive-intake.md)。扫描本身不会下载媒体或自动提交收件；停用来源保留历史，永久删除来源不删除已归档作品。本文负责用户流程，查询与扫描实现见[发现来源架构](../architecture/archive-discovery.md)。

## 扫描与人工接纳

同页的“发现来源”页签默认填写 E-Hentai 完整上传者名称并自动识别账号，数字 UID 收入高级选项。来源不会定时扫描或自行收件；管理员只能手动执行“扫描最新”或在存在历史游标时“继续扫描更早内容”。每次最多持久化 100 条结果，并区分新归档、已有活动任务、已归档且未变化、可能更新和替代版本。只有新归档、可能更新和替代版本可由管理员勾选，选定模式与画质后加入既有收件箱，解析后遵循同一自动或手动入队规则。

上传者来源可以归档和重新启用，长期保留最新、增量和历史游标。扫描只有在完整成功后推进对应游标；失败、取消、暂停或 Worker 租约恢复不推进游标。扫描使用 `ARCHIVE_UPLOADER_SCAN@v1`，与 URL 解析共同占用 `ARCHIVE_RESOLVE` lane；E-Hentai 搜索请求保持三秒最小间隔并与下载共享 Provider penalty，但不会被活动下载 lease 阻塞。

## 导航与筛选

### 从艺术家管理查找和关联来源

本节于 2026-10-24 核验。艺术家管理的行操作提供「归档来源」菜单，可在新标签页打开 E-Hentai，以艺术家名称构造与关键词来源相同的远端标题搜索；艺术家与社团使用同一流程。查询通过共享契约校验和编码，名称含不支持字符时提示在创建表单中修改，不静默删改查询。原站结果由管理员查看，页面不读取外站结果，也不创建扫描任务。

「创建关键词来源」复用现有表单，预填名称为关键词、预选当前艺术家，均可编辑；来源名称留空时使用关键词。表单提供原站搜索入口，使用当前关键词及上传者限制；已有上传者集合与尚未识别的新增名称不能同时搜索，避免丢失限制。原站改词后需同步修改表单；原站登录、筛选和本地规则可能使正式扫描结果不同。取消、重开及切换艺术家重置草稿，父组件重新渲染不覆盖正在编辑的内容。

艺术家管理的「归档来源」列独立于身份／标签来源，反查实际固定艺术家关系，同时展示上传者与关键词来源：无关联时可快捷创建；一个来源直接显示名称链接；多个来源显示数量并展开列表。停用来源仍计入并标注停用。点击名称在当前标签页进入来源详情，浏览器返回保留艺术家列表的 URL 筛选、排序与分页。名称遵循隐私遮蔽，数量、类型和状态保持可读。

艺术家入口保存时，规范化相同的条件仍复用原来源。若所选艺术家已有绑定则完成；缺少绑定时，展示已有来源、原绑定与待追加艺术家，由用户明确选择追加、查看原来源或取消。追加只添加缺失关系，不覆盖旧绑定、不改来源名称和启停状态、不建立作品或待生效关系。保存成功留在艺术家列表并显式刷新，不启动扫描或下载；刷新失败与保存失败分开提示。

`archiveSearch.appendDefaultCreators` 使用管理鉴权，在来源锁和创作者锁内重查来源、规则版本、艺术家有效性及并集上限，以唯一关系幂等追加。来源删除、规则变化或艺术家合并时不写入，保留草稿并要求重新保存条件确认。本功能无需迁移或 Worker 变更；回退 App 不移除已保存关系，关系仍可由现有来源详情管理。验收证据见[艺术家来源入口验证](../records/features/artist-discovery-sources-2026-10-24.md)。

### 来源工作区

发现来源在 PC 和手机均使用全宽列表与独立详情视图：无 `sourceId` 时显示列表，有则显示详情，不再自动预选首个来源。详情隐藏重复的工作区标题、页签和列表工具区，提供“返回来源列表”。两端共用查询、操作和业务组件，屏幕宽度只控制布局与结果滚动方式。

工作区 Tab 位于页面标题栏右侧；发现来源不再重复显示区块标题和说明。搜索、启停筛选与来源操作共用工具栏首行，类型和数量筛选位于第二行；窄屏自动换行，整个工具栏滚动后吸附在后台导航下方。

来源在可用宽度充足时以约 48px 高的紧凑单行展示名称和查询条件、待处理数量、异常数量、扫描状态与最近扫描时间；长名称和条件省略，手机及窄容器按需换行，不设大块最小行高。列表默认隐藏停用来源，可按名称/UID/上传者/关键词搜索，并组合来源类型、启停、有待处理、有异常筛选。沿用完整来源查询，在完整集合上筛选和排序后展示全宽虚拟滚动列表，不使用表头或分页；PC 和手机均随页面滚动，仅渲染可视范围及缓冲区域。

工具栏提供名称、创建时间、更新时间、待处理数量的升序和降序，默认按创建时间从新到旧；所选字段优先，不再按启停状态分组。同值以来源 ID 升序确定顺序，名称按中文自然顺序比较并识别数字。待处理数量使用列表展示的 `actionable` 统计。数量未加载时显示占位，依赖数量的筛选和排序等待统计，不能将未知当作零。筛选与排序不变时，轮询更新现有行数据但保留行顺序，新来源追加到末尾；切换筛选或排序、重新加载页面时重新排序。

排序写入 URL 的 `sourceSort`：`name-asc/desc`、`created-asc/desc`、`updated-asc/desc`、`actionable-asc/desc`，默认 `created-desc` 省略，非法值回退默认。刷新、分享链接及浏览器前进/后退恢复排序，进入来源详情及返回时保留排序。切换排序清空勾选，并按对应筛选与排序恢复浏览位置；其余来源筛选仍在当前页面访问内保留。

导航仍使用 `/admin/archive/inbox`：默认打开发现来源页签，`tab=uploaders` 仍可显式定位发现来源，`tab=inbox` 打开第二个页签收件队列；`sourceId` 定位来源详情，`discoveryView=ignored` 打开与来源详情同级的全局已忽略视图。原有 `itemId` 收件深链保持有效并优先打开收件队列，关闭收件详情时保留 `tab=inbox`，显式切换工作区时清理另一工作区的定位参数。列表进入详情可通过浏览器返回；详情内换源替换当前详情记录。直接打开详情链接时，页面返回按钮仍可回到来源列表。失效来源提供返回入口，加载错误提供重试，不把请求失败当作来源被删除。

本次页面访问内，从详情返回列表再进入同一来源会保留来源筛选、排序、来源勾选和列表滚动位置，以及同来源的内容筛选、未提交勾选、入箱选项和浏览位置；切换不同来源时清空勾选并恢复 AUTO/ORIGINAL。进入详情前保存可见来源及其偏移，返回时由虚拟列表在完成测量后统一恢复；不在卸载后读取已被页面高度变化重置的滚动位置。页面返回按钮和浏览器后退使用同一恢复规则。断点切换不清空勾选或增加导航历史；刷新恢复 URL 定位与来源排序，不持久化未提交勾选。轮询后已不具备操作资格的项目会从选择中移除。新增上传者、关键词及另存条件后统一进入返回的来源，UID 冲突跳转使用相同入口；删除当前来源后返回列表。

详情头常显来源身份、关键状态及扫描操作，活动扫描可直接取消；低频来源管理动作集中在更多菜单，扫描覆盖、历史详情和固定艺术家配置可展开查看。需要处理的错误和 UID 提示直接展示。结果工具栏保留范围和列表/首图/卡片切换，入箱模式及画质以摘要显示，点击后在设置弹窗中调整，单项与批量入箱共用当前选项。

内容默认查看待处理，保留处理中、已归档、异常、全部状态。标题搜索常驻，提交搜索后生效；更多筛选放入桌面弹出面板/手机底部面板，编辑草稿并点击“应用筛选”后统一生效。支持内容分类、语言多选、发布时间区间、发布时间未知及仅看未绑定；已应用条件可单独移除或清空。切换状态、应用搜索/筛选时清空勾选并提示，重置内容位置；加载更多保留选择。

已关联未删除且 `ACTIVE` 的本地作品时，后续收件或下载取消不会把发现记录归入异常：仍有 `POSSIBLE_UPDATE` 差异时回到“可能更新”，否则显示“已归档”，列表不再显示该次取消的错误文案。收件历史清理前后使用同一规则，状态统计与列表一致；取消历史保留在任务记录中。仍有更新的作品可以再次加入收件箱，无需等待旧取消记录清理；首次归档取消、实际失败、身份重复、活动任务和回收站规则保持原有语义。此调整不需要数据迁移，发布后读取现有记录即可生效。

内容筛选由数据库在游标分页前执行，结果与统计共用过滤条件，不过滤已加载的局部列表。标题搜索覆盖显示标题和快照别名，按字面包含匹配；分类读取 `comparisonSnapshot.category`，不混用归档判断 classification。语言来自快照 language 命名空间的有效语言值白名单（含无对白），排除 translated 等修饰标签，不推断日语。分类/语言同维度取并集，各维度取交集；缺失信息可通过“未知”筛选。日期按浏览器本地日历转换为包含起始日、排除结束日次日零点的区间，只匹配 `postedAt`；未知日期与日期范围互斥。

勾选结果后显示底部批量操作条，选择数量只显示一次，操作按钮不重复数量；手机端只显示带可访问名称的图标按钮，保持单行，操作较多时在操作区横向滚动。全局已忽略提供恢复操作。手机操作条位于应用主导航上方，并为结果内容预留空间。发现结果与全局已忽略共用虚拟列表滚动组件：桌面在固定高度结果区滚动，手机结果随页面滚动，不再形成嵌套纵向滚动。列表每批加载 50 条、最多选择 100 条，恢复浏览位置时以当前数据中的条目和偏移为依据，避免沿用尺寸或数据变化前的测量结果。

## 上传者名称识别

两类新增来源表单共用名称输入：停止输入一秒后核验完整名称，单轮等待上限二十秒。已保存上传者按名称提供候选；选择已有账号不必再次联网。输入仍按名称解释，包括纯数字名称；手动数字 UID 需显式打开高级选项。

点击保存会等待当前识别，成功后一次保存账号与名称；缺少公开画廊、无身份依据、限流、超时或访问失败时保留名称条件，并明确提示“按名称搜索”。无效查询字符必须修正，不能退化成不限上传者。相同名称在途识别合并，改名或关闭后旧响应失效，超时中止 Provider 请求；识别不创建扫描、收件或下载任务。

新增上传者命中已有来源时直接打开原记录，不自动恢复停用状态，也不合并历史。旧名称来源以中性的“按名称搜索”展示，下次人工扫描继续自动识别；可从更多菜单识别账号，手动纠错仍保留扫描范围复核确认。

标题来源的名称限制与 UID 限制互斥，分别去重；名称条件同时验证标题和上传者元数据，未命中项仍计入候选和续扫进度。条件保存后冻结，未来账号识别不修改原条件，可通过“另存为精确账号筛选”重新识别并另存。展示名称不参与去重键、匹配和游标，复用旧 UID 条件时只补充缺失展示名称，不改变状态、名称、条件或扫描历史。

## 标题关键词来源

“发现来源”可切换上传者和标题关键词两类。关键词来源保存一个普通文本关键词，匹配方式默认为“包含”，也可选“开头是”或“结尾是”；可选填写完整上传者名称：识别成功保存 UID 条件，暂未识别则保存名称条件；留空才表示不限上传者。名称可改，远端条件只能另存来源；本地组合规则可预览全部候选后原地应用。规范化相同的查询复用原记录，不修改原名称或停用状态；停用来源可重新启用。

本地规则独立检查英/日标题，支持逐条选择是否忽略大小写及安全正则，组合规则和标题高亮以[标题来源规则](./archive-title-rules.md)为准。远端关键词仍按普通文本构造受限的标题短语与可选上传者查询；不能无歧义表达的双引号、星号、百分号及控制字符会明确报错，具体校验以共享 Zod 契约为准。本地正则不会改变远端搜索范围。

每次检查最多 **100 个去重远端候选**，不是收集 100 个匹配。界面分别显示检查数、匹配数及停止原因；零匹配仍可能有后续。进度依据过滤前候选计算，续扫游标绑定来源和冻结条件；扫描失败、取消或租约丢失不提交目录和游标。新任务为 `ARCHIVE_SEARCH_SCAN@v5`（保留 v1/v2/v3/v4 执行兼容），与上传者扫描复用请求治理和批量元数据，不逐画廊读取媒体详情。

有效接纳候选可入箱；不匹配候选在来源内“已过滤”列表复核，可手动接纳、确认排除或恢复遵循规则。人工决定按来源保留，不删除其他来源、归档或媒体，不写全局忽略。入箱在全局身份锁下再次校验当前匹配及工作流，防止旧页面误提交。最终仍需人工勾选并选择模式与画质，再经收件解析完成归档；扫描本身不会自动提交候选。

覆盖范围仅限远端搜索实际返回的候选，不承诺全站任意文本检索，也不能靠最新水位自动补齐历史作品改标题后的命中。本地组合规则、人工决定和升级限制见[标题来源规则](./archive-title-rules.md)；早期实现证据见[历史设计](../design/e-hentai-title-keyword-scan.md)。

### 多上传者 UID 限定

标题关键词来源支持最多 10 个精确账号，可逐个通过名称识别、已保存候选或高级 UID 输入后点击“添加上传者”，支持移除。保存也会包含当前尚未点击添加的输入。多账号为 OR，与标题条件为 AND；UID 去前导零、按数值排序并去重，展示名称不参与查询、来源去重或游标绑定。列表只剩一个 UID 时沿用旧单账号格式及查询指纹。

没有已添加账号时仍支持单个名称识别失败后按名称保存；已有账号时，未识别名称会阻止保存并保留输入，需重试识别、填写 UID 或清除此输入，不能静默忽略。整条远端多账号搜索最多 200 字符，超限明确提示缩短关键词或减少账号，不截断条件。原站查询使用标题短语和 OR 上传者项，语法与长度依据 [EHWiki Gallery Searching](https://ehwiki.org/wiki/Gallery_Searching)。

远端条件不可原地修改；另存完整账号集合并从独立游标开始。本地规则调整保留原来源和游标。列表与详情展示全部账号。多上传者 JSON 沿用 v3 格式；任务版本、规则字段与人工决定的升级边界详见[标题来源精准匹配](./archive-title-rules.md)。

## 发现来源的艺术家绑定

发现来源通过统一的“新增来源”弹窗创建，使用 Tab 切换上传者与标题关键词，两类表单保留各自草稿，共享当前选择的艺术家。关键词表单先填标题关键词，再填可选来源名称；创建或另存时，名称为空（含全空白）则使用去除首尾空白的标题关键词，自定义名称优先。创建时可选最多 200 个固定艺术家／社团；关闭后清空草稿，保存期间禁止切换类型或关闭。两类创建接口接受可选 `artistIds`，去重并验证艺术家仍有效，来源与固定艺术家关系在同一事务中保存。重复来源沿用原记录及其绑定，不覆盖原配置；需要修改时从详情调整。弹窗容器只负责切换和共享选择，上传者与关键词的状态、校验、提交分别由独立 Hook 管理。 新增、另存与重命名弹窗将表单内容放在独立滚动区，头部和保存操作固定；关键词来源的上传者限定默认折叠，重命名时展开显示冻结条件。艺术家绑定通过独立搜索面板多选，候选列表单独滚动，显示同名记录的 ID 和社团身份；完成选择返回来源草稿，仍需保存来源才会建立固定绑定。手机键盘缩小可视区域时，这些弹窗随可视高度和偏移调整，不将候选列表放在可能被裁剪的绝对定位下拉层中。

发现来源支持配置最多 200 个固定艺术家／社团。标题来源只在人工加入收件箱时读取当前配置并追加，扫描、复核和重算不建立关系。上传者来源每次创建扫描任务时冻结配置，扫描期间修改配置只影响下一次任务；画廊首次匹配时追加这些艺术家：本地已有有效作品立即生效，否则保存为待生效绑定，归档发布成功时在同一事务中应用。绑定不会启动归档或下载。

上传者来源的“首次匹配”由 Catalog 的 `firstMatchedAt` 表示，与全局 NEW 分类无关；不匹配结果变为匹配时才消耗机会。空配置、全局忽略、回收站作品或手动抑制也会消耗首次机会，不会在以后扫描中隐式补绑。迁移把已有匹配结果标记为历史结果，历史补绑需手动选择。

发现结果支持混合状态多选与已加载结果全选，每批最多 100 项。绑定追加并去重，不替换已有作者；忽略与加入收件箱各处理符合条件的子集。“仅看未绑定”在服务端分页前排除已有有效作者或待生效作者的画廊，标签计数同步使用该筛选。

待生效绑定按 provider/gallery/artist 唯一，跨来源共享；来源删除、归档失败或取消不丢失。`discoveryView=pending-creators` 是全局待生效管理入口，每条表示一组画廊／艺术家关系，可批量取消。取消只影响仍待生效的关系，已生效关系在作品管理修改。

手动取消或移除写入独立抑制记录，阻止所有发现来源再次自动追加该画廊的该艺术家；显式手动重新绑定解除抑制。不同 gallery ID 独立，原站 artist/group 标签同步仍遵循原有 SOURCE 证据语义。来源配置变化不追溯修改已经保存的关系。

批量绑定和取消使用持久逐项操作回执。网络结果未知时重用原请求编号，已知失败项重试使用新编号。这两类回执永久保留，避免清理后重放旧请求恢复已经取消的关系。写接口使用管理 procedure、读取使用会话认证，操作者从会话取得，画廊身份由服务端 Catalog 解析。

发现来源作品行常驻显示“已绑定：名字”“待生效：名字”，两者均无时显示“未绑定艺术家”，名称遵循隐私模式。封面和标题通过受保护目录跳转在新标签页打开外部原站；站内原站预览已退役。有本地作品且未删除时，右侧独立提供“查看本地作品”入口，不受可更新等操作状态遮挡。其余行区域点击切换选择，复选框保留键盘操作，均遵守最多 100 条的选择限制。状态与艺术家绑定同行排列，GID、分类、语言、页数及时间合为紧凑元数据，不重复展示来源 URL。单条与批量忽略均先确认，弹窗固定本次对象并显示单条标题或实际可忽略数量，说明跨来源持续生效和恢复入口；失败保留弹窗重试，成功保留撤销。此调整不改变绑定、忽略或恢复数据语义，无迁移，回退 App 即可恢复旧交互。

## 结果展示

来源结果和全局已忽略共用“纯列表 / 首图预览 / 卡片”偏好，通过现有 Zustand persist 保存在当前浏览器 localStorage，不写用户数据库；默认纯列表，旧偏好继续有效。存储不可用时仍可在内存切换。原站在新标签页打开，来源页面保留当前筛选、展示偏好和位置；旧站内预览返回恢复机制已退役。首图在手机上使用 128×192px，640px 及以上使用 160×224px。卡片上方完整显示封面（高 288px，不裁切），下方显示标题、可用的艺术家绑定、状态、内容分类、语言、页数和时间；旧记录没有页数时省略，页数读取已有比较快照，不新增扫描。已忽略显示保留的来源与忽略时间。

卡片按结果区域宽度排列：不足 600px 一列，600px 起两列，960px 起三列；移动端一列。发现来源工作区使用后台可用宽度，列数计算不包含后台导航和来源侧栏。卡片按行虚拟滚动，保留触底分页、跨来源位置恢复和最多 100 条选择；切换模式或调整列数按作品身份恢复所在行。

来源和全局已忽略的卡片图片及标题均在新标签页打开原站；已忽略记录缺少目录关联时，该入口不可用。无首图或加载失败时保留同尺寸占位，封面与标题的原站导航仍可使用。图片和敏感摘要沿用隐私模式。无数据库迁移。

## 发现来源批量扫描

来源列表支持逐项勾选、全选当前筛选结果中的可扫描来源和“批量扫描最新”。虚拟滚动保留勾选；全选覆盖完整筛选结果，不限于当前渲染的行；切换搜索/筛选清空勾选并提示；停用和已有活动扫描的来源不可选。启动面板冻结来源顺序，提示包含补全未扫描历史。每次只允许一个未结束批次，暂停中的批次也占用该位置。

后台按固定顺序处理来源：连续 LATEST 直到增量游标耗尽，再连续 HISTORY 直到历史游标耗尽，之后处理下一个来源。首次来源会补完整个历史；历史已完整的来源只追新增。本批不会在补历史后再次回头追扫描期间新发布的内容。NAME 自动绑定 UID 后重新从 LATEST 核对 UID 覆盖。每轮沿用 100 个候选上限、限流、去重、创作者绑定与重试策略；不自动创建收件或下载。

启动和实际扫描均检查来源资格，已删除、停用或被其他扫描占用的来源跳过。单来源最终失败后继续其余来源，终态汇总可仅重试失败及父任务基础设施故障时尚未处理的来源。新批次创建前取消失败父任务遗留的活动子扫描，避免来源永久占用。

暂停阻止后续轮次，已排队子任务直接暂停，运行中的一轮完成后保留游标；若该轮转入重试等待，父暂停状态阻止再次领取。恢复沿检查点继续；取消安全中断当前轮、停止后续派发，保留已发现结果，未提交轮次可能在下次重扫。任务中心对子任务的暂停、继续和取消转交所属批次。

页面的持久批次卡展示来源级已处理/总数、成功/失败/跳过、当前阶段和本轮检查数，支持逐来源结果与详情导航。活动批次每 3 秒刷新，关闭页面不停止任务，重新进入恢复状态。来源名及错误摘要遵循隐私显示与脱敏规则。

批次使用 ARCHIVE_DISCOVERY_BATCH_SCAN@v1 和 SystemJob 父子关系；payload 保存来源顺序，result 保存检查点与控制意图。父任务每次只运行一个短事务，原子创建单轮扫描与保存检查点，通过 preserveAttempt 让出解析通道，避免占道等待子任务。请求 ID 幂等、事务锁和数据库活动批次唯一索引共同防重。扫描历史沿用 30 天清理，活动父批次依赖的扫描记录排除在清理范围外；父任务检查点沿用 SystemJob 保留方式，不依赖短期事件记录。

发布需执行 20260920120000_add_discovery_batch_scan 迁移，扩展任务通道约束并增加活动批次唯一索引，无新增表或数据回填。App 与 Worker 协调升级；回退前取消并等待活动批次及子任务终止，保留扩展约束、索引、来源目录和游标。

## 统计与加载

发现来源页先加载来源资料和作品，状态数字使用独立的 `archiveSearch.catalogCounts` 查询异步补齐。
来源列表、详情和分页请求显式传入 `includeCounts: false`；未返回的统计显示占位，不能当作零。
统计失败只显示局部重试提示，已有统计保留，来源选择和作品浏览仍可使用。

全来源统计包含停用来源，由来源列表和当前详情共用；标题、分类、语言、日期和“仅看未绑定”的统计按来源与已应用条件独立缓存，不影响全来源统计。
切换状态分类及翻页不重算数量。活动扫描或处理中记录触发 3 秒轮询；空闲使用 60 秒 staleTime
及过期后的焦点刷新，离开发现标签停止轮询。入箱、忽略、恢复、删除、创作者绑定和扫描批次变化
会失效统计缓存。首次看到历史已完成扫描不再额外刷新结果；实际观察到完成转换仍会刷新。

统计接口经独立 HTTP 请求传输，其他 tRPC 接口保留批量传输，避免统计拖住同批的来源资料。
计数和作品查询是独立快照，刷新期间可以短暂不同步；这些数字不作为写操作授权或并发控制依据。
索引与技术边界见[发现来源架构](../architecture/archive-discovery.md)，既有验证结果见[查询性能记录](../design/archive-discovery-query-performance.md)。

## 停用、删除与恢复

上传者和标题关键词来源均支持单项永久删除，启用、停用状态都可直接删除。停用继续保留身份、游标和发现历史；删除则清除来源及其扫描记录、扫描明细和长期发现目录。确认弹窗读取来源名称、扫描记录数和发现结果数，实际删除事务再次核对最新状态。

排队、运行、等待重试、暂停及正在取消的扫描会阻止删除。弹窗可以取消扫描，等待领域扫描和关联任务都结束后，管理员仍须再次点击“确认删除”；取消成功不会自动删除来源。删除与创建扫描、入箱及忽略处置复用来源事务锁，避免旧页面在删除提交后继续产生收件或忽略记录。

已经创建的收件项目、归档下载任务、通用任务与事件、本地作品、来源引用、媒体文件以及其他来源的发现结果均保留，活动解析或下载继续执行。全局忽略记录只解除与被删来源的关联，保留来源名称快照；“全局已忽略”入口不依赖来源列表，即使删掉最后一个来源也可查看和恢复。

重复删除返回已删除结果。删除后重新新增相同上传者身份或关键词条件会创建新来源，从头扫描，不恢复旧游标；已有归档和全局忽略仍按既有身份规则识别。本功能不提供回收站或批量删除，恢复原发现历史只能依赖删除前的数据库备份。实现沿用现有外键，无数据库迁移或 Worker 契约变更；回退 App 版本不会恢复已经删除的发现历史。

## 查询失败与遗留扫描恢复

Worker 领取标题扫描后，在可统一结算错误的边界内校验冻结查询；校验失败不访问远端、不重试，在同一结算事务中将扫描与后台任务置为失败，并保留错误。旧版本可能留下后台任务 FAILED、扫描 PENDING 的组合。恢复前备份相关扫描记录，按精确任务 ID 锁定关联的两行，仅在任务 FAILED、无租约且扫描 PENDING、检查数为零时，将任务错误与结束时间同步到扫描；保留任务历史，不重置游标、不删除来源或作品。

发布核验应以运行镜像的 revision 为准：当前发布工作流在分支上手动构建只推送 SHA 标签，只有 v 版本标签构建会更新 latest。重启现有容器不会切换已拉取的新镜像。旧失败记录也不会因发布自动恢复。

## 忽略与删除的区别

全局忽略按 Provider 与画廊身份保留，是跨来源的长期人工决定，不随扫描历史清理。忽略不删除本地作品和文件；恢复忽略后，仍有目录记录的候选可重新显示，否则需重新扫描。来源内标题排除仅作用于该来源，详见[标题规则](./archive-title-rules.md)。作品删除意图独立于忽略，自动收件不能绕过[回收站规则](./archive-trash.md)。

## 验收条件

覆盖最新／历史游标、零匹配推进、失败不推进、名单与过滤前分页、人工决定与抑制、批次暂停／取消／重试、来源删除并发及全局忽略恢复。恢复旧发现历史依赖删除前数据库备份；回退页面不能恢复数据。已保存的目录和游标不因布局回退而变化。标题规则的现有开发证据见[验证记录](../records/features/archive-title-rules.md)。
