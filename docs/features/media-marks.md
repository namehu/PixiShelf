# 单图书签与喜欢

书签保存回看位置，单图喜欢保存个人偏爱的媒体。两个状态独立，同一媒体可以同时拥有。图片、动图和视频均支持，视频标记整段内容，不记录播放秒数。它们不修改[作品评分](./artwork-rating.md)、作品喜欢计数或作品的 `likedOnly` 筛选。

## 操作与集中浏览

作品详情右上角“更多作品操作”提供“只看喜欢的图片”勾选项，按当前账户的单图喜欢记录筛选整部作品，保留原有媒体顺序与序号，图片、动图和视频使用同一逻辑媒体身份。它与“只看未读”互斥切换，取消勾选恢复全部媒体；切换暂停自动浏览并回到媒体列表顶部。完整列表、堆叠浏览及由详情打开的预览沿用筛选结果。取消单图喜欢保存成功后刷新结果；筛选仅作用于当前详情访问，不记忆到其他作品或账户。加载、失败重试和无喜欢图片分别展示，空态仍可查看全部图片和使用作品评分。

作品详情的完整列表与堆叠浏览在尚未喜欢时隐藏单图爱心；双击画面或从图片菜单添加喜欢后，图片左下角显示爱心，随媒体滚动，点击取消后消失。堆叠只绑定当前真实媒体 ID。视频下方操作行遵循同一显隐规则，未喜欢时仍可从原“图片操作”菜单添加喜欢，不改变视频画面手势。静态图片、GIF、APNG 与 WebP 画面单击无操作，双击只添加单图喜欢，已喜欢时仍反馈且不重复保存。双击要求同一媒体两次短按间隔不超过 300ms、落点相距不超过 40px；移动超过 10px、长按、多指、取消和堆叠横滑会清掉待配对短按。双击落点显示约 800ms 的粉色实心爱心，轻旋转、弹性放大后上浮约 80px 并淡出，可连续叠加；减少动态效果时改为短暂静态爱心。标记尚未就绪或不可用时不显示成功反馈。按钮添加沿用按钮弹动，取消不飘心。喜欢操作（含键盘激活按钮）暂停详情自动滚动／堆叠自动翻阅，须手动继续。

图片长按／右键、聚焦画面后按 Enter／Space 打开同一图片菜单，其中“进入全屏阅读”打开既有适配预览，关闭后按最后真实媒体 ID 回定位；“查看原始文件”仍是独立入口。GIF／APNG／WebP 的播放按钮位于右下角，操作按钮不参与画面双击或长按。已喜欢的视频爱心位于下方已有操作行左侧，右侧保留“图片操作”菜单按钮及右键，播放器原手势和长按倍速保持。适配预览默认在底部居中按“书签—轮播／动图控制—喜欢”排列，书签和未喜欢爱心均保持可用，以手机 44px／桌面 48px 控件高度垂直对齐，图标为 24px，组间距在手机为 4px、桌面为 24px；窄屏精简中央计数和动图文案，保持同排并保留手机安全区域，单图无轮播时仍在底部显示张数。适配预览支持鼠标滚轮上下切图，空格切换当前图片喜欢状态，双击／双击触屏添加喜欢（已喜欢时保持且不重复保存），并在实际落点播放与详情同一浮心反馈；浮心位于预览公共层，切图或关闭即清理，不受缩放变换影响。标记未就绪或不可用时不显示成功反馈；双击不再缩放，双指缩放保留。张数统一在底部显示，顶部不重复。空格长按不重复触发，输入框、按钮和设置面板保留自身键盘操作。原图预览继续提供书签、爱心按钮；沉浸阅读在更多抽屉的“当前图片”分组仅提供单图喜欢，不提供书签入口，原有作品爱心仍操作作品评分。触控区域至少 44px，按钮显示选中状态及对应的取消操作。预览仅在用户主动添加标记时播放缩放反馈，切图及状态回填不触发；系统减少动态效果时保留静态选中反馈。各入口按账户与逻辑媒体共享状态，连续操作串行保存，失败恢复已确认状态并提示。

适配预览工具组可通过独立拖动把手停靠到底部、左侧或右侧，两侧纵向居中；拖动与分端记忆见[自动浏览控制](./artwork-auto-browse.md#控制与默认值)。标记读取失败仍保留菜单／全屏重试入口，侧边工具栏内重试进入正常布局，避免滚动容器裁剪。

适配预览的标记按钮常驻弹窗公共层，切图只切换逻辑媒体绑定。当前、前一张、后两张标记通过现有批量接口读取，跳过 15 秒内有效缓存；每张媒体仍使用独立的账户隔离缓存、请求取消和保存版本校验。初次读取保持图标及透明度稳定，未知状态禁用操作，不显示上一张的选中状态；读取失败提供重试，迟到读取不覆盖新操作。

详情喜欢筛选使用 `mediaMark.likedMediaIds` 按当前账户和活动作品返回完整的已喜欢逻辑媒体 ID 集合，只在启用筛选时读取，不受媒体详情首批 24 项或批量标记读取 200 项上限截断。它复用单图标记确认后的账户缓存失效机制，不传输整部作品的完整媒体详情。

`/my-images` 提供“书签”和“喜欢的图片”两个标签，默认书签。桌面入口位于账户菜单，手机入口位于“更多”的收藏索引分组。每页 24 项，分别按书签或喜欢时间倒序，同时间以记录 ID 排序；重复设置为已有值不改变时间。取消后重新添加使用新的标记时间。

卡片展示媒体缩略图、作品名及作品内逻辑序号，遵循现有隐私遮蔽。列表具有加载、空态、错误重试和分页。首版没有备注、文件夹、批量操作、公开计数或单图喜欢等级。

详情完整列表、堆叠浏览与视频下方操作行的已喜欢按钮显示粉色实心裸爱心，普通、悬停、按下及禁用状态均无底色、边框或阴影，仅键盘聚焦时显示焦点轮廓。详情与预览浮层共用 24px 心形图标及手机 44px／桌面 48px 触控区域；预览保持原有底色，未喜欢显示描边心，选中后填充，书签保留原有配色。单图喜欢仍是独立开关，不表示作品评分档位。

## 点击与阅读

卡片进入 `/artworks/{id}?mediaId={mediaId}`。服务端与阅读器使用当前逻辑媒体身份，动画／视频组合以显示项主 ID 保存一次标记，不为隐藏原件另建副本；沉浸阅读的封面占位项不能标记。

显式媒体目标优先于 `resume=1`，仅消费本次定位意图，保留其他 URL 参数与 hash。完整列表定位到目标，堆叠模式展开目标所属组并选中相应成员；等待阅读索引和目标媒体就绪后完成定位。定位前暂停阅读上报，不把初始第一页误记为已读，也不弹普通续读提示。目标不存在时提示失效，不按旧数组序号跳到其他图片。添加书签或喜欢本身不产生阅读记录。

## 数据、鉴权与生命周期

`mediaMark.getMany/set/list/remove` 均要求会话与 `expectedUserId` 一致，实际账户来自 Session。设置是明确的 `kind + value` 赋值，单独更新一个状态；批量读取最多 200 个媒体 ID。列表只返回当前账户，移除按独立标记 ID 和状态执行，因此失效条目仍可清理。服务在作品锁与事务内校验活动状态、媒体归属和写入状态。

独立标记保存书签／喜欢时间、作品与媒体引用以及作品名、逻辑序号、媒体类型快照。相同账户和有效媒体最多一条记录；两个状态都取消后删除记录。媒体引用可空，失效时保留“原媒体已失效”卡片，不显示旧路径图片、不跳转，两个状态仍能独立移除。

| 变化                                       | 标记处理                                               |
| ------------------------------------------ | ------------------------------------------------------ |
| 当前正常扫描、排序、仍保留 Image ID 的维护 | 保留                                                   |
| 图片删除、完整媒体替换或重建               | Image 外键置空，保留失效条目                           |
| 应用内同 ID 原文件覆写成功                 | 断开旧媒体引用；写入开始、结束和标记操作使用一致作品锁 |
| 正在写入／替换                             | 暂不可标记或从收藏跳转；替换回滚恢复原标记             |
| 视频无损重新封装                           | 作为同媒体维护保留                                     |
| 作品回收／恢复                             | 回收期间隐藏，恢复后重新可见                           |
| 永久删除作品或账户                         | 级联清除相应标记                                       |

首版不识别外部直接覆盖同路径文件后的字节变化，不增加文件哈希、源 stat 身份或按文件名／序号自动重绑。临时网络与媒体加载失败不等于媒体已被删除。

## 升级与验收

使用正式新增表 migration 和 Prisma generate/deploy，保留既有作品、阅读和评分数据，不回填默认标记。隔离数据库验证完整迁移、旧库升级及约束；实例升级遵循[备份与恢复](../operations/backup-and-recovery.md)。回退应用时保留新增表与个人标记，旧版本媒体写入者不具备本功能的同 ID 覆写失效保护，回退期间应暂停此类写入。

验收覆盖独立开关、幂等、快速连续操作、四入口同步、账户切换与迟到响应、动画组合去重、分页、失效移除、删除／替换／回收／恢复以及显式定位的阅读保护。工程与浏览器结果记录在[单图标记验证记录](../records/features/media-marks.md)、[预览控件验证记录](../records/features/viewer-controls-2026-10-29.md)、[详情交互验证记录](../records/features/detail-media-interactions-2026-10-30.md)、[预览工具栏与筛选联合验证](../records/features/preview-controls-and-filters-2026-10-31.md)和[详情裸爱心验证](../records/features/detail-bare-like-2026-10-31.md)，手机真机覆盖单独说明。
