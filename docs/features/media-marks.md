# 单图书签与喜欢

书签保存回看位置，单图喜欢保存个人偏爱的媒体。两个状态独立，同一媒体可以同时拥有。图片、动图和视频均支持，视频标记整段内容，不记录播放秒数。它们不修改[作品评分](./artwork-rating.md)、作品喜欢计数或作品的 `likedOnly` 筛选。

## 操作与集中浏览

作品详情通过图片长按／右键菜单操作；视频提供“图片操作”按钮打开同一菜单并支持右键，保留播放器长按倍速。适配预览和原图预览在右下角提供书签、爱心按钮，适配预览在窄屏上避开底部播放控件，并保留手机安全区域；沉浸阅读在更多抽屉的“当前图片”分组仅提供单图喜欢，不提供书签入口，原有作品爱心仍操作作品评分。触控区域至少 44px，按钮显示选中状态及对应的取消操作。预览按钮提供按压和选中动效，系统减少动态效果时保留静态选中反馈。各入口按账户与逻辑媒体共享状态，连续操作串行保存，失败恢复已确认状态并提示。

`/my-images` 提供“书签”和“喜欢的图片”两个标签，默认书签。桌面入口位于账户菜单，手机入口位于“更多”的收藏索引分组。每页 24 项，分别按书签或喜欢时间倒序，同时间以记录 ID 排序；重复设置为已有值不改变时间。取消后重新添加使用新的标记时间。

卡片展示媒体缩略图、作品名及作品内逻辑序号，遵循现有隐私遮蔽。列表具有加载、空态、错误重试和分页。首版没有备注、文件夹、批量操作、公开计数或单图喜欢等级。

## 点击与阅读

卡片进入 `/artworks/{id}?mediaId={mediaId}`。服务端与阅读器使用当前逻辑媒体身份，动画／视频组合以显示项主 ID 保存一次标记，不为隐藏原件另建副本；沉浸阅读的封面占位项不能标记。

显式媒体目标优先于 `resume=1`，仅消费本次定位意图，保留其他 URL 参数与 hash。完整列表定位到目标，堆叠模式展开目标所属组并选中相应成员；等待阅读索引和目标媒体就绪后完成定位。定位前暂停阅读上报，不把初始第一页误记为已读，也不弹普通续读提示。目标不存在时提示失效，不按旧数组序号跳到其他图片。添加书签或喜欢本身不产生阅读记录。

## 数据、鉴权与生命周期

`mediaMark.getMany/set/list/remove` 均要求会话与 `expectedUserId` 一致，实际账户来自 Session。设置是明确的 `kind + value` 赋值，单独更新一个状态；批量读取最多 200 个媒体 ID。列表只返回当前账户，移除按独立标记 ID 和状态执行，因此失效条目仍可清理。服务在作品锁与事务内校验活动状态、媒体归属和写入状态。

独立标记保存书签／喜欢时间、作品与媒体引用以及作品名、逻辑序号、媒体类型快照。相同账户和有效媒体最多一条记录；两个状态都取消后删除记录。媒体引用可空，失效时保留“原媒体已失效”卡片，不显示旧路径图片、不跳转，两个状态仍能独立移除。

| 变化 | 标记处理 |
| --- | --- |
| 当前正常扫描、排序、仍保留 Image ID 的维护 | 保留 |
| 图片删除、完整媒体替换或重建 | Image 外键置空，保留失效条目 |
| 应用内同 ID 原文件覆写成功 | 断开旧媒体引用；写入开始、结束和标记操作使用一致作品锁 |
| 正在写入／替换 | 暂不可标记或从收藏跳转；替换回滚恢复原标记 |
| 视频无损重新封装 | 作为同媒体维护保留 |
| 作品回收／恢复 | 回收期间隐藏，恢复后重新可见 |
| 永久删除作品或账户 | 级联清除相应标记 |

首版不识别外部直接覆盖同路径文件后的字节变化，不增加文件哈希、源 stat 身份或按文件名／序号自动重绑。临时网络与媒体加载失败不等于媒体已被删除。

## 升级与验收

使用正式新增表 migration 和 Prisma generate/deploy，保留既有作品、阅读和评分数据，不回填默认标记。隔离数据库验证完整迁移、旧库升级及约束；实例升级遵循[备份与恢复](../operations/backup-and-recovery.md)。回退应用时保留新增表与个人标记，旧版本媒体写入者不具备本功能的同 ID 覆写失效保护，回退期间应暂停此类写入。

验收覆盖独立开关、幂等、快速连续操作、四入口同步、账户切换与迟到响应、动画组合去重、分页、失效移除、删除／替换／回收／恢复以及显式定位的阅读保护。工程与浏览器结果记录在[验证记录](../records/features/media-marks.md)，手机真机覆盖单独说明。
