# 作品堆叠浏览

旧视觉摘要已由用户部署使用，实际缩减效果不足。本次代码将其替换为即时堆叠浏览；本文描述当前工作区实现，不表示新版本已经发布。目标 NAS 的真实手感仍须单独验收。

## 分组与浏览

每次进入作品详情默认「完整」，可切换为「堆叠」。沿用阅读列宽和原始媒体顺序，上下浏览各叠、左右翻阅组内图片。没有生成等待、视觉相似度判断或纵向展开入口，不读取原图做分析。

前后端使用同一确定性函数。完整索引中可独立展示的静态图片总数为 N，每组容量为 `min(8, max(4, ceil(N / 80)))`。每段连续静态图片分成 `ceil(段长 / 容量)` 组，余数从前往后均匀分配；每组最多 8 张。100、300、1,000 张纯静态作品分别形成 25、75、125 叠。动画、视频和既有多成员逻辑媒体作为独立项并截断静态分组。

每叠首张为初始封面；同页保留各叠当前成员，离页重进归零。画框依封面比例和视口可用高度确定，最高 720px，组内翻页保持高度，图片完整容纳。图片和底部导航合成一张带窄留边的相纸；两张 CSS 背卡分别向左倾斜 3°、向右倾斜 4°，配合横纵错位与接触阴影形成叠放，背卡不加载图片。两侧为背卡预留空间，拖动时整张前卡随手指平移并轻微倾斜；减少动态效果时保留平移，取消动态倾斜。底部左侧显示原始序号范围和组内位置刻度，右侧集中显示页码及至少 44px 的翻页按钮。桌面支持拖动、按钮、焦点内左右键；窄屏支持横滑，纵向手势保留页面滚动。组首组尾停止，不跨组或循环。

切换模式、继续阅读和关闭预览按真实媒体 ID 定位，目标在组内时直接显示该张。预览沿用整部作品当前筛选后的受支持媒体序列；视频保持详情播放。退出预览定位最后浏览图片。隐私遮蔽、键盘焦点和减少动态效果沿用现有规则。本文的预览指点击图片打开的「适配尺寸预览」。长按「查看原始文件」仍是独立原图阅读器，按真实媒体 ID 映射完整阅读索引进入，沿用全量逐图记账；它与独立沉浸浏览不继承堆叠模式或未读过滤。

「只看未读」冻结进入时的候选 ID，并在完整分组内取交集；不重新打包，不因新记为已读而让卡片消失。交集首张作为该轮画框封面。刷新未读才更新候选。

## 自动浏览与记账

堆叠自动翻阅依原顺序逐张显示，到组尾才纵向进入下一叠；复用预览轮播的停留时间、循环、加载等待、失败暂停、重试及跳过。完整模式继续使用自动滚动。手动操作、模式切换及进入预览暂停自动浏览；详情和预览不会同时驱动。

堆叠画框加载成功、翻页稳定且至少一半进入视口后，真实观察的该张可授予原始整组已读。来自堆叠模式的预览沿用整组授予；完整模式逐图记账。历史已读不撤回。背页、邻图预加载、过渡和导航定位不产生 VIEW、活动时间或最后位置；最后位置始终为实际观察的媒体，而非组尾。

VIEW 可携带 `stack: { ruleVersion: 1, fingerprint, groupId }`，与旧 `summary` 互斥。客户端成员名单不进入请求。服务端在作品锁与既有阅读事务中，每批一次读取权威媒体索引，验证版本、顺序指纹、组归属以及真实观察媒体属于该组，再由服务端计算授予成员。任一无效 stack 凭据令整批失败，返回 `ARTWORK_STACK_CONFLICT`，不产生部分写入。账户、作品、mediaRevision 仍按现有契约核验。

媒体更新使分页或分组凭据失效时，停止旧采集并提示重新打开。显式重新打开用按账户和作品隔离、60 秒过期且消费一次的会话锚点恢复浏览模式和真实媒体 ID；目标已删除则退到首项。普通新进入仍默认完整。浏览器禁用存储时安全刷新，不承诺跨刷新位置恢复。

## 数据与任务兼容

无需新增数据库表或 migration。继续使用原阅读索引和分页缓存（每页 24 项、最多并发 2 批、最多缓存 8 批）。虚拟行按稳定组 ID 定位，组内活动成员独立维护；只挂载窗口中的当前图，分页元数据请求限于可见行和有限邻项，不为纸边加载整组原图。轻量全量索引仍随作品大小增长。

关闭 `artwork.summaryGenerate`、通用 `job.enqueueBackgroundJob` 和创建新任务的 `retry` 入口，统一拒绝 `ARTWORK_SUMMARY_GENERATE`。保留已经存在的任务执行、暂停、恢复、取消、历史及 Worker capability；不改变 executor 合约。已存在任务仍可能继续完成，停止新增不等于停止旧任务。

保留 `ArtworkSummary`、`ArtworkSummaryFeature`、源变动触发器、Worker 分析能力和历史已读。旧 summary 查询及 `VIEW.summary`/`reading.summaryGroupRead` 请求仍按旧发布快照核验；旧客户端生成按钮会收到退役提示。本期不删除历史数据、不重算已读、不做破坏性清理。

回退代码可恢复旧界面，但也会恢复生成入口；回退前应刷新客户端，不能把新 stack 请求交给不识别该字段的旧服务。优先前向修复。生产升级仍遵循[备份与恢复](../operations/backup-and-recovery.md)；本次没有修改生产数据库或服务。

## 验证边界

目标设备：i5-4210M，2 核 4 线程，12GB DDR3，原图通过 NFS 来自另一台 NAS 的 8TB 机械盘。新路径取消了逐图特征解码和 Worker 分析开销，仍受媒体请求、NFS、图片服务和浏览器性能影响；开发机不能替代目标设备实测。

自动化覆盖分组数量与余数、媒体边界、未读交集、真实位置、批次授予、伪造与过期凭据、旧 summary 请求、停止新增任务，以及自动跨组和单一浏览驱动。隔离 PostgreSQL 回归覆盖原子授予、排序变化及原阅读不变量。真实浏览器与完整工程门禁结果记录在本次交付中；NAS、真机触控和生产升级分别报告，未实测不得标为通过。
