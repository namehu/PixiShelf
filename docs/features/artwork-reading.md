# 作品阅读记录与进度

本页记录本地作品阅读功能的用户语义与验收证据。功能正在隔离环境验收，不能据此推断生产实例已经迁移或发布。实现约束及完整验收矩阵见[架构设计](../design/artwork-reading-tracking.md)。

## 用户行为

- 阅读记录按账户隔离，同账户跨设备共享。详情长图、自适应预览、独立原图预览和沉浸阅读使用同一计数规则；原站缩略图预览不计入。
- 手动和自动浏览均在媒体加载成功、页面在前台且媒体进入视口时立即计入，不要求中央区域或停留时长；同屏多个媒体分别计入。预加载、遮挡弹层、离屏、后台和加载错误不计入。隐私遮罩不停止记录。
- 本次阅读上报由服务端确认作品从未完成变为已看完后，底部居中显示 2 秒的轻量「已看完」提示。同一账户、作品和媒体版本在当前页面会话中只提示一次；打开已看完作品、重复上报和心跳不会重复提示。
- 有待发送阅读事件时按 1 秒合并上报，持续有效展示期间每 60 秒产生心跳；无待发送事件时不请求。离开阅读页或切到后台时尝试立即提交剩余事件。
- 同一作品的有效阅读活动间隔超过 30 分钟才增加一次访问次数。刷新、切换浏览模式和短时间回访沿用同一次访问；有效心跳只延长已有活动，不能创建首次访问。
- 进度按完整作品的不同逻辑媒体计数。既有 APNG/视频分组的成员共同代表一个展示项；跳读只增加实际看过的项，不把最大序号前面的项推定为已读。零媒体作品不判为已看完。
- 普通打开从头开始；进入详情时存在第二张及以后的恢复位置，才在底部提示「上次看到第 X 张，是否继续？」并显示 8 秒倒计时进度条。点击「跳转」回到本次进入时捕获的位置，点击「从头开始」回到第一张；超时仅关闭提示，不自动跳转。提示每次进入只出现一次，离开、账户切换或媒体失效时撤销，不因自动阅读更新再次出现。最后媒体已不存在时沿用服务端恢复位置回退规则。
- 卡片阅读徽章贴住封面左上角，统一灰色背景与浅灰内容：未看显示小书签图标，阅读中只显示环形进度条、不显示数值，已看完不显示徽章；悬停提示与无障碍描述保留完整状态及进度。偏好标签避让徽章。详情显示完整阅读数据；最近阅读按最后阅读时间排序。阅读状态筛选与原有筛选、排序组合时使用稳定游标。列表里已显示的卡片只原位更新标记，刷新后才重新套用筛选顺序。

### 补看与手动完成

- 详情只保留轻量进度文字；只看未读、查看全部、刷新未读和标记全部已读统一放在右上角作品操作菜单，不重复底部操作栏。完成后显示「已读完 · 600 张」。未读空态只保留说明与一个查看全部入口。图片上不显示阅读角标或状态条；长按菜单只显示「第 X 张」，不展示已读／未读状态；仅加载失败且尚未记读的图片提供单张「标记已读」。详情预览仅沿用原有页码导航。加载失败不阻止手动标记。
- 未读筛选进入时冻结本轮候选 ID，列表与自适应预览共用该集合。自动或手动读完只更新状态，不移除图片；显式刷新后才移除。全部读完仍可回看，刷新为空后提示「没有未读内容」。筛选或刷新会暂停自动浏览并定位列表开头，重新打开作品默认查看全部；独立阅读器不增加筛选入口。
- 手动标记只有正向操作，不支持改未读、重置或多选。整部标记由服务端选择当前作品的全部逻辑媒体，不受浏览器懒加载或筛选范围限制；后续新增媒体仍为未读。
- 进度与次数独立。手动标记不增加阅读次数、不更改实际阅读时间、恢复位置或最近阅读排序；从未访问的作品也能处于部分已读或全部已读。自动 VIEW 继续按原有活动窗口计次，不因手动操作而延长窗口。滚动到底不会自动标记前面的遗漏。
- 未读为零已读项，阅读中为部分已读，完成要求总数大于零且全部已读。最近阅读只包含实际产生过 VIEW 的作品；不将手动完成解释为一次阅读活动。
- 手动写入确认后才更新界面，失败提示重试，提交期间禁止重复操作；媒体版本冲突要求重新打开，不能对新版本自动重试旧操作。

## 数据变化与恢复

迁移 `20260924130000_add_artwork_reading_tracking` 为现有 `Artwork` 增加默认值为 1 的 `mediaRevision`，新增账户作品摘要与已读媒体集合；不回填过去的阅读。没有记录的旧作品显示未看，不代表过去从未阅读。软删除保留记录；永久删除通过外键级联清理。

普通媒体增删、排序保留仍存在的已读媒体，下次打开时校正进度快照。完整替换、恢复或全量重建在同一事务中递增版本并清空该作品所有账户的阅读摘要、次数、已读集合与恢复位置；迟到的旧版本上报被拒绝。媒体写入与阅读上报统一先锁作品，再处理媒体或阅读状态。客户端的待发送事件不构成持久离线队列，强制关闭或持续断网可能丢失最后尚未提交的一批。

版本冲突后的“重新打开”会完整刷新当前阅读页面，同时重新获取展示媒体与阅读上下文；刷新完成前旧采集器保持失效，不能用新版本重放旧媒体事件。跨设备心跳只延长已有、未超时且已看过该逻辑媒体的活动，不依赖其他设备修改的最后位置，也不改写恢复位置。客户端摘要以按账户隔离的查询缓存为准，使用 `(mediaRevision, stateVersion)` 比较版本，后续查询和上报仅能用较新快照替换已确认状态（包括重建后的零进度）；逐项已读 ID 与汇总原子更新，旧响应不能使进度倒退。路径迁移发布同样先锁 Artwork，再更新 Image，避免与手动重排、删除及阅读写入形成反向锁序。

发布前应建立数据库、原媒体、派生媒体、配置和镜像的一致检查点，随后使用 `db:generate` 与 `db:deploy`，禁止 `db:push`。回滚代码时保留新列和表，并暂停旧版本的完整重建写入者；若旧版本已经重建作品，重新升级前须核对受影响作品、清空其旧阅读数据并递增版本。影响范围无法确认时不得直接恢复阅读功能。详见[备份与恢复](../operations/backup-and-recovery.md)。

迁移 `20261009090000_reading_manual_progress` 将摘要的 `lastViewedAt`、`lastActiveAt` 改为可空，增加默认 0 的 `stateVersion`，保留现有值。首次手动标记的次数为 0、阅读时间与恢复位置为空；`firstSeenAt` 表示首次记为已读的时间，包含手动操作，不是实际观看证据。服务端在作品锁内随状态变化递增版本，幂等重复标记不增加版本。

**该迁移不能直接回退到旧应用**：旧代码对空阅读时间调用 `toISOString()` 会失败。优先部署兼容空时间的修复版本；必须回到旧代码时，按一致检查点恢复数据库、媒体、配置与镜像，不反向补造日期或仅强制改回 NOT NULL。

## 范围外

本功能不回填历史阅读，不提供改为未读、重置、多选批量修改、访问流水、统计仪表盘、视频秒级进度或持久离线队列。访问次数不用于权限判断，也不改变原媒体的备份责任。
