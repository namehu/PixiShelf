# 作品阅读记录与进度

本文维护当前工作区的用户语义。数据、版本和上报机制见[阅读架构](../architecture/reading.md)，本次迁移与验证见[实施记录](../records/features/artwork-reading-position-2026-11-04.md)。`current` 不代表生产已部署。

## 阅读位置与完成

- 阅读按账户隔离，同账户跨设备共享。图片、动图与视频按完整作品逻辑序列计数，APNG/视频组合只算一个展示项；堆叠和筛选不改变分母。
- 进度保存最远阅读位置形成的前缀。跳到第 80 项并产生有效阅读后，显示已读 80 项；回看第 20 项只改变最后位置，最远位置和进度仍为 80。进度不再表示逐项实际观察过的数量。
- 到达最后逻辑项，或点击「标记已读完」，即完成整部作品。完成后普通追加媒体仍显示 100%，不因分母增大退回阅读中。零媒体不能通过新观察或手动操作完成；迁移保留的旧完成状态不被重新解释。
- 完整替换、替换恢复或全量重建清空该作品所有账户的阅读状态与次数。[EH 原图升级](./archive-quality.md)在来源和逐页身份均验证通过后保留 Image ID、阅读状态与次数。普通增删、重排保留真实访问和完成标记，并在媒体发布事务内维护锚点；最远位置重定位成为新末项时也完成作品。
- 未读是无阅读前缀且无真实访问；有前缀或已开始观看但未完成的视频属于阅读中；已完成以持久化标记为准。取消「只看未读媒体」和单项「标记已读」，保留作品列表的阅读状态筛选及整部「标记已读完」。

## 观察、保存和访问次数

详情完整模式图片及动图的区域进入前台视口即产生有效观察，包括详情占位、下载中与加载失败区域，不要求停留时长。适配预览、独立原图预览、沉浸浏览和堆叠仍要求加载成功及真实可见。预加载、离屏、后台、弹层遮挡和原站外链不计阅读；隐私遮罩不停止记录。

有效观察立即预测进度，每 3 秒合并保存；离页尽力补交。短暂失败重试，最终失败或事件过期撤回未确认预测并提示未保存。刷新、关闭标签或进程终止可能丢失最后尚未确认的事件；不提供持久离线队列。完成时立即显示 2 秒「已看完」轻提示，同一账户/作品/布局版本在当前应用会话中不重复；提示不代表已经落库，打开已完成作品或仅收到确认不触发。

同一作品有效活动间隔达到 30 分钟才增加一次访问，短时切换模式、刷新或回访沿用当前访问。有效心跳每 60 秒延长尚未超时的活动，不建立首次访问，也不改变最后位置。真实阅读日期、最后位置仅由有效 VIEW 更新，按观察时间选择最新事件，迟到的旧观察不能覆盖新的位置。

视频实际开始播放计访问和最近阅读；播放位置达到有效正数总时长的 90% 才推进阅读前缀。快进满足条件也算，回拖与循环不撤销；结束事件补交有效总时长的完成证据。时长未知时只记录活动，可手动完成。封面、元数据、自动播放被拒绝不算开始；暂停、缓冲、后台与被遮挡时不发送活动心跳。APNG/视频组合遵循视频主项门槛，不持久化或跨设备恢复播放秒数。

## 详情、卡片与继续阅读

详情顶部与底部显示相同的前缀进度、剩余数量和真实访问次数。未完成显示「已读 X / N · 剩余 M」，完成显示「已读完 · N 张」。底部紧凑排列，仅错误时展开错误文字；双勾按钮「标记已读完」具有可访问名称和至少 44px 点击区域。上下文加载、失效、提交中、零媒体和已完成时禁用。提交失败撤销预测并可重试；手动完成不改变最远/最后位置、次数、阅读时间或最近阅读排序。

普通进入详情停在顶部，不因索引加载跳到首图。存在第 2 项以后的恢复位置时，提示「上次看到第 X 张，是否继续？」并显示 8 秒倒计时；「跳转」使用进入时捕获的位置，「从头开始」回首项，超时只关闭。每次进入只提示一次；账户切换、离开或布局失效撤销提示。定位过程不把经过的首屏内容误记为阅读。

共用作品卡片在封面右下角显示蓝点「阅读中」或红点「未读」，已读和未知摘要不显示。普通/简约模式一致；摘要按当前账户批量读取，不逐卡请求。已有卡片只原位更新状态，刷新或重新应用筛选才重新排序/过滤，带阅读条件的本轮列表与滚动位置保持稳定；查询缓存按账户隔离。

### 首页继续阅读

首页「继续阅读」最多 6 部，按本账户最后真实阅读时间、作品 ID 倒序。候选要求有真实访问、非空阅读时间、非空逻辑媒体、未完成、ACTIVE 且未删除；视频已开始但未完成可以入选，手动/默认完成不会制造访问。服务端先过滤再取上限。无候选隐藏，失败提供重试；回首页和重新聚焦重新查询。

点击继续阅读卡片携带一次性 `resume=1`。详情等待当前账户最新状态后定位，消费该参数并保留其他参数与 hash，不再显示普通续读提示。优先恢复最后媒体身份；普通媒体删除时，由发布事务退到旧序列最近存续前项，无前项取新首项。没有有效最后位置时使用首项，不寻找“第一个未读项”。

### 堆叠浏览

堆叠画框加载成功、翻页稳定且至少一半可见时，阅读前缀推进到静态组尾；最后位置仍是实际观察项。来自堆叠的适配预览沿用该规则，独立原始文件阅读器逐项推进；隐藏成员不制造 VIEW、时间或访问。完整交互见[堆叠浏览](./artwork-summary.md)。

### 媒体信息与阅读预估

作者/来源信息下方保留逻辑媒体总数、原文件大小与预计阅读时间。大小汇总全部原文件，APNG/同名视频两份均计入；缺失显示已知合计和缺失数。预估固定每逻辑项 1 秒，1–59 项显示不到 1 分钟，60 项起向上取整，零项隐藏；不根据阅读前缀计算剩余时间。媒体菜单显示选中原文件格式和大小，缺失显示大小未知。验证见[媒体信息记录](../records/features/media-size-reading-estimate-2026-11-03.md)。

## 数据变化、升级与恢复

普通媒体更新先按身份保留锚点；逻辑代表变化沿存活组成员，删除则沿旧序列回退至最近存续前项。最远锚点无前项时清空，最后锚点无前项取新首项。缓存逻辑总数、布局版本及所有账户位置与媒体变化同事务发布。已完成标记保持，不会由普通新增、删除或排序清除。

布局变化拒绝旧版本上报并要求重新打开，同时获取媒体和阅读上下文；不能用新版本重放旧观察。切账户清理旧队列并忽略迟到响应。完整重建同时清空记录并推进布局版本，不能由仅回退客户端规避。

`20261104010000_reading_position_progress` 将旧摘要和已读行的账户/作品并集转换为单行位置。旧摘要在旧规则下已达 90% 的完成状态明确保留，包含总数快照陈旧的情况；其余以当前逻辑序列中的旧已读最大位置为前缀，到末项则完成。保留次数、真实日期、创建时间及仍有效的最后媒体，不补造手工操作的空日期；旧两表解除业务外键后封存。

发布须停全部写入者，建立数据库、原媒体、派生媒体、配置和配套程序的一致检查点并完成隔离恢复，随后正式 `db:generate` / `db:deploy`。Web App 与 Worker 配套升级。独立 Android 客户端按用户要求暂停使用，原生专项和最终 release 不阻塞 Web 交付；旧阅读协议不兼容，服务端不提供旧客户端兼容分支，后续若恢复客户端须升级。封存表仅为迁移证据，不能恢复上线后的新位置写入，也不能直接恢复旧应用；优先前向修复，必要时整套检查点恢复。验收后至少观察 7 天才发布独立清理 migration，详见[迁移手册](../operations/runbooks/reading-position-migration.md)和[备份基线](../operations/backup-and-recovery.md)。

## 验收条件与范围

验证须覆盖跳到第 80 项形成 80 项前缀、回看不后退、末项与手动完成、完成后新增仍 100%、普通删除/排序重定位、完整重建失效、账户与布局隔离、最新观察时间、视频开始/90%门槛、堆叠组尾、预测失败撤销及跨设备一致。迁移须验证旧 90% 与陈旧快照保留、只有已读行、空日期、零媒体、分组 parity、失败整事务回滚及封存不受业务删除影响。

不提供改未读、重置、逐项补看筛选、访问流水、统计仪表盘、视频秒级续播或持久离线队列。Pixiv 新作品可通过显式账户偏好默认完成，见[导入默认已读](./pixiv-import-reading.md)。本地、隔离、浏览器、真机和生产证据分别记载，历史旧集合语义见[旧验证记录](../records/features/artwork-reading.md)。
