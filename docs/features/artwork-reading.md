# 作品阅读记录与进度

本页记录本地作品阅读功能的用户语义与验收证据。功能正在隔离环境验收，不能据此推断生产实例已经迁移或发布。实现约束及完整验收矩阵见[架构设计](../design/artwork-reading-tracking.md)。

## 用户行为

- 阅读记录按账户隔离，同账户跨设备共享。详情长图、自适应预览、独立原图预览和沉浸阅读使用同一计数规则；原站外链不计入；站内原站预览已退役。
- 图片和动图在加载成功、页面在前台且进入视口时立即计入，不要求中央区域或停留时长；同屏多个媒体分别计入。视频使用下述播放位置规则。预加载、遮挡弹层、离屏、后台和加载错误不计入。隐私遮罩不停止记录。
- 有效阅读使本地预测进度从未完成变为已看完时，立即在底部居中显示 2 秒的轻量「已看完」提示，不等待 3 秒合并或接口响应。同一账户、作品和媒体版本在当前应用会话中只提示一次；切换预览、离页返回、保存失败后重试或重新阅读都不重复提示。打开已看完作品、服务端确认和心跳不触发该提示。提示表示本次阅读已完成，不表示进度已落库；最终无法保存时另行显示全局未保存提示并撤销未确认的进度。
- 有效阅读立即在本页预测已读集合和数量，自动事件从首条开始按 3 秒合并上报（不因后续事件推迟），每批最多 100 条并串行拆批。持续有效展示期间每 60 秒产生心跳；无待发送事件时不请求。应用根级 ReadingProvider 持有内存队列，详情卸载只清理观察并立即补交，不销毁队列；在途请求后的剩余事件继续提交。切后台及 pagehide 尽力补交，但刷新、关闭标签或进程终止可能丢失未确认事件。
- 同一作品的有效阅读活动间隔超过 30 分钟才增加一次访问次数。刷新、切换浏览模式和短时间回访沿用同一次访问；有效心跳只延长已有活动，不能创建首次访问。
- 进度按完整作品的不同逻辑媒体计数。既有 APNG/视频分组的成员共同代表一个展示项；跳读只增加实际看过的项，不把最大序号前面的项推定为已读。零媒体作品不判为已看完。
- 普通打开从头开始；进入详情时存在第二张及以后的恢复位置，才在底部提示「上次看到第 X 张，是否继续？」并显示 8 秒倒计时进度条。点击「跳转」回到本次进入时捕获的位置，点击「从头开始」回到第一张；超时仅关闭提示，不自动跳转。提示每次进入只出现一次，离开、账户切换或媒体失效时撤销，不因自动阅读更新再次出现。最后媒体已不存在时沿用服务端恢复位置回退规则。
- 卡片阅读标识为贴住封面左上角的 12px 小三角：未看用红色，阅读中用蓝色，已看完不显示；不显示书签图标或环形进度。不额外提供阅读状态悬停提示或具体进度描述。偏好标签固定在原位置，不因阅读标识移动，且与三角不重叠。详情显示完整阅读数据；最近阅读按最后阅读时间排序。阅读状态筛选与原有筛选、排序组合时使用稳定游标。列表里已显示的卡片只原位更新标记，刷新后才重新套用筛选顺序。

### 堆叠浏览（2026-10-22）

详情「完整／堆叠」采用全量索引的确定性连续分组。堆叠画框至少一半可见且加载、翻页稳定后，实际观察图片授予原始整组已读；从堆叠打开的适配尺寸预览同样授予整组；独立原始文件阅读器保持全量逐图规则。完整模式维持逐图观察。隐藏成员不产生 VIEW、活动时间或最后位置；未读筛选取冻结交集且保留原组边界。

`VIEW.stack` 为 `{ ruleVersion: 1, fingerprint, groupId }`，与 `summary` 互斥；服务端每批读取一次权威索引，校验真实媒体与组归属后计算成员，不接收客户端成员表。源变化或伪造凭据整批拒绝并失效阅读器，保留历史已读。显式重新打开可恢复该账户和作品的真实图片锚点，普通新进入仍从完整模式开始。旧 `VIEW.summary` 兼容保留。完整边界见[作品堆叠浏览](./artwork-summary.md)。

### 大作品详情加载与预测进度（2026-10-20）

- SSR 使用独立查询，只带首批 24 个逻辑媒体详情及作品摘要。认证后的初始化接口一次返回精简全量索引和账户阅读上下文；成员映射仅在索引中传输一次，客户端重建阅读上下文。索引仍随作品项数增长，不宣称全部数据均为常数大小。
- 详情、适配预览和独立预览共用分页数据源，按 24 个逻辑媒体获取完整详情；请求合并、最多并发 2 批、最多缓存 8 批，视口和相邻批次优先。独立预览也采用虚拟 slides。选页直接获取目标批次，顺序校对仅在打开时读取完整编辑集合。
- 所有序列按 sortOrder、id 排序，并保留 APNG/视频分组。分页指纹覆盖媒体 revision、成员顺序、分组和占位尺寸；普通增删或排序即使不增加 mediaRevision，也会令旧分页请求冲突。客户端不能混用不同指纹的数据。
- 初始化缓存按账户、作品和 SSR 指纹隔离。重新打开已增删或重排的作品时，旧访问的索引不会参与新 SSR 的冲突判定；本次接口实际返回不同指纹时仍要求重新打开。
- 进度栏在加载、失败、成功和版本失效期间预留固定高度。未知完整媒体使用精简索引尺寸占位，只有详情加载成功后才进入播放器和阅读采集。
- 展示进度由已确认快照叠加待确认事件计算，不伪造服务器 stateVersion。响应只确认本批事件，失败重试保留 60 秒有效期内的事件，过期或明确拒绝撤销预测；手动标记立即预测并提交，失败撤销。完成提示跟随本地预测立即反馈，跨设备以落库结果为准。
- 自动保存按作品和批次保留截止时间：超过 100 条的同批事件串行续传，请求期间新产生的事件从首条起另等 3 秒，不能被上一次响应提前提交。退出某作品只提前提交该作品当时的待保存事件；若已有请求在途，剩余事件在其结束后续传。切后台或 pagehide 尽力补交所有作品。
- 自动事件最终过期、被拒绝或因版本失效被丢弃时，显示带作品编号的全局未保存提示，离开详情后仍可见；短暂失败继续重试，不反复弹出最终失败提示。切换账户清除旧账户提示，并忽略旧请求的迟到成功或失败。主动切换账户仍会清理旧账户内存队列，不提供跨账户或持久离线重放。
- 不新增服务端未持久化写缓冲、离线持久队列、数据库 migration 或部署配置。回退代码即可恢复旧前端/API，数据库与原媒体无需恢复；测试仅使用隔离 reading_perf 数据库和合成图片，不修改现有图库。

### 补看与手动完成

- 详情只保留轻量进度文字；只看未读、查看全部、刷新未读和标记全部已读统一放在右上角作品操作菜单，不重复底部操作栏。完成后显示「已读完 · 600 张」。未读空态只保留说明与一个查看全部入口。图片上不显示阅读角标或状态条；长按菜单只显示「第 X 张」，不展示已读／未读状态；仅加载失败且尚未记读的图片提供单张「标记已读」。详情预览仅沿用原有页码导航。加载失败不阻止手动标记。
- 未读筛选进入时冻结本轮候选 ID，列表与自适应预览共用该集合。自动或手动读完只更新状态，不移除图片；显式刷新后才移除。全部读完仍可回看，刷新为空后提示「没有未读内容」。筛选或刷新会暂停自动浏览并定位列表开头，重新打开作品默认查看全部；独立阅读器不增加筛选入口。
- 手动标记只有正向操作，不支持改未读、重置或多选。整部标记由服务端选择当前作品的全部逻辑媒体，不受浏览器懒加载或筛选范围限制；后续新增媒体仍为未读。
- 进度与次数独立。手动标记不增加阅读次数、不更改实际阅读时间、恢复位置或最近阅读排序；从未访问的作品也能处于部分已读或全部已读。自动 VIEW 继续按原有活动窗口计次，不因手动操作而延长窗口。滚动到底不会自动标记前面的遗漏。
- 未读为零已读项且没有有效观看访问，阅读中包含部分已读或已经开始观看但未完成的视频，完成要求总数大于零且全部已读。最近阅读只包含实际产生过 VIEW 的作品；不将手动完成解释为一次阅读活动。
- 手动标记立即更新本地预测并提交，失败撤销预测并提示重试，提交期间禁止重复操作；媒体版本冲突要求重新打开，不能对新版本自动重试旧操作。

## 数据变化与恢复

### 视频观看状态（2026-10-18）

- 详情和独立原图预览的播放器、沉浸浏览采用相同规则：视频实际开始播放后计入访问及最近阅读，状态为阅读中；有效播放位置达到有限正数总时长的 90% 时，该逻辑媒体才计为已读。快进到 90% 也算完成，回拖及循环不撤销已读。
- 仅显示封面、加载元数据、自动播放被拒绝不算开始观看。时长未知或无效时可以记录已经开始观看，但不能自动完成；现有手动标记全部已读仍可使用。图片和独立动图维持原规则，APNG/视频分组遵循视频主项规则。
- 暂停或缓冲时不发送视频活动心跳；前台、在屏和未被面板遮挡的门禁继续适用。快进发生在开始播放之后时，可在暂停状态下完成判定。原有已读数据保留，不重算旧视频。
- `VIEW` 和 `HEARTBEAT` 可携带临时 `playback: { currentTime, duration }`；两值必须是有限非负数。服务端按数据库中的逻辑媒体类型判定，视频缺少播放证据的旧客户端上报被忽略，不能因显示封面而完成。完成比例只影响已读集合，开始观看仍正常建立访问；心跳仅延长已有且未超时的访问。
- 沿用现有摘要的访问次数和已读集合，不新增表或迁移、不持久化视频秒数，也不新增跨次或跨设备断点续播。列表筛选与摘要统一将有观看访问但零已读项识别为阅读中。发布时刷新旧客户端；回滚旧代码会恢复旧视频判定，建议用前向修复保留新语义。本次不修改已有业务数据，无需数据恢复操作。

迁移 `20260924130000_add_artwork_reading_tracking` 为现有 `Artwork` 增加默认值为 1 的 `mediaRevision`，新增账户作品摘要与已读媒体集合；不回填过去的阅读。没有记录的旧作品显示未看，不代表过去从未阅读。软删除保留记录；永久删除通过外键级联清理。

普通媒体增删、排序保留仍存在的已读媒体，下次打开时校正进度快照。完整替换、恢复或全量重建在同一事务中递增版本并清空该作品所有账户的阅读摘要、次数、已读集合与恢复位置；迟到的旧版本上报被拒绝。媒体写入与阅读上报统一先锁作品，再处理媒体或阅读状态。客户端的待发送事件不构成持久离线队列，强制关闭或持续断网可能丢失最后尚未提交的一批。

版本冲突后的“重新打开”会完整刷新当前阅读页面，同时重新获取展示媒体与阅读上下文；刷新完成前旧采集器保持失效，不能用新版本重放旧媒体事件。跨设备心跳只延长已有、未超时的活动：图片要求已看过该逻辑媒体，视频要求有效播放证据但不要求已完成；心跳不依赖其他设备修改的最后位置，也不改写恢复位置。客户端摘要以按账户隔离的查询缓存为准，使用 `(mediaRevision, stateVersion)` 比较版本，后续查询和上报仅能用较新快照替换已确认状态（包括重建后的零进度）；逐项已读 ID 与汇总原子更新，旧响应不能使进度倒退。路径迁移发布同样先锁 Artwork，再更新 Image，避免与手动重排、删除及阅读写入形成反向锁序。

发布前应建立数据库、原媒体、派生媒体、配置和镜像的一致检查点，随后使用 `db:generate` 与 `db:deploy`，禁止 `db:push`。回滚代码时保留新列和表，并暂停旧版本的完整重建写入者；若旧版本已经重建作品，重新升级前须核对受影响作品、清空其旧阅读数据并递增版本。影响范围无法确认时不得直接恢复阅读功能。详见[备份与恢复](../operations/backup-and-recovery.md)。

迁移 `20261009090000_reading_manual_progress` 将摘要的 `lastViewedAt`、`lastActiveAt` 改为可空，增加默认 0 的 `stateVersion`，保留现有值。首次手动标记的次数为 0、阅读时间与恢复位置为空；`firstSeenAt` 表示首次记为已读的时间，包含手动操作，不是实际观看证据。服务端在作品锁内随状态变化递增版本，幂等重复标记不增加版本。

**该迁移不能直接回退到旧应用**：旧代码对空阅读时间调用 `toISOString()` 会失败。优先部署兼容空时间的修复版本；必须回到旧代码时，按一致检查点恢复数据库、媒体、配置与镜像，不反向补造日期或仅强制改回 NOT NULL。
