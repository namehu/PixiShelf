# 作品评分与喜欢

本文负责评分档位、详情与沉浸操作入口及其共同状态。喜欢集合的筛选和分页见[作品搜索与我的喜欢](./artwork-search-and-favorites.md)，公共账户边界见[权限说明](../security/access-control.md)。评分属于账户整理数据，不是公开平均分。

针对某一张图片的爱心属于[单图喜欢](./media-marks.md)，与这里的作品评分独立；“我的图片”与作品级“我的喜欢”分别展示各自集合。

## 统一档位与爱心

| 显示位置 | 文案   | 持久状态                | 爱心与我的喜欢 |
| -------- | ------ | ----------------------- | -------------- |
| 0        | 未评分 | 无记录，接口返回 `null` | 未亮，不包含   |
| 1        | 一般   | `level = 1`             | 未亮，不包含   |
| 2        | 喜欢   | `level = 2`             | 点亮，包含     |
| 3        | 超爱   | `level = 3`             | 点亮，包含     |
| 4        | 夯爆了 | `level = 4`             | 点亮，包含     |

五个位置含默认的未评分，实际评价有四档；不换算为十分制。中文文案与有序数值分离。评分是唯一可写状态，`isLike` 由 `level >= 2` 派生；“我的喜欢”和 `likeCount` 使用相同阈值，每个账户最多贡献一次。

沉浸浏览单击未亮爱心将未评分或一般设为喜欢；单击已亮爱心清除评分，包括超爱和夯爆了。单击即时响应，不增加双击评分手势。亮心提示“取消喜欢并清除评分”，同时提供当前档位。保存遵循[本轮列表稳定性](./artwork-search-and-favorites.md#本轮列表稳定性)：即使喜欢条件生效，取消成功也只原位更新状态，当前作品及播放位置保留，重新查询候选时才移出。失败恢复最后确认状态。

长按作品爱心 500ms 打开紧凑选档弹层，更多菜单的“作品评分”打开同一入口。弹层提供喜欢、超爱、夯爆了和清除评分，标明当前档位；打开本身不写入，成功确认后关闭，失败留在原处并可重试。长按后的松手不触发单击，移动超过 10px、指针取消、失焦或切作品取消待触发长按。弹层支持键盘选档、Escape 关闭与焦点回到爱心；打开暂停自动浏览，关闭不自动恢复。沉浸爱心以珊瑚红单心、玫红双心、深红星芒心分别表达喜欢、超爱和夯爆了，不叠加档位文字；悬停提示与可访问名称保留当前档位，颜色之外也可用形状区分。保存期间保持爱心，使用独立小型加载提示。

本功能提供详情评分和沉浸爱心选档，不新增评分专用筛选、排序、批量评分或收藏夹。

## 详情底部滑杆

入口为右下角悬浮操作组中的评分。入口不依赖当前可导航媒体数量，单图、单视频及“只看未读”无可见媒体时仍可使用；自动浏览复用同一操作组。媒体预览期间避免叠加详情操作入口。

操作按钮围绕右下角主按钮向左上方扇形展开。点击评分收起操作组，在屏幕底部居中显示 Dialog，使用 toast 所在区域但不改变全站 toast 配置。面板约 360px 宽、窄屏不超过视口减 32px，距底部 24px 并计入安全区域；背景轻微压暗。打开期间隐藏同位置尚未处理的继续阅读提示，关闭后恢复。

面板以紧凑卡片显示当前档位、五位置胶囊滑杆和刻度文案。Dialog 标题只供辅助技术读取，界面不显示“我的评分”、拖动提示、常驻保存状态或关闭图标。打开不写入；拖动即时预览，松手、点击选档或键盘提交后保存。取消拖动恢复此前选择。点击背景或按 Escape 关闭，关闭后焦点回到右下角主按钮。

视觉随档位从中性空轨、蓝灰、亮蓝、蓝靛到蓝紫满格变化，配合白色圆润滑块、吸附弹性和档位文字过渡。主动进入夯爆了时播放短时光晕、流光与星芒，最长 4 秒；重新打开已有高评分不重复庆祝。关闭停止面板动画，减少动态效果偏好停用庆祝及位移动画。支持明暗主题、至少 44px 操作区域、方向键、Home/End 与中文档位朗读。

浮层阻挡状态按来源合并。打开评分暂停自动浏览和阅读计时，关闭不会擅自恢复自动浏览。

## 保存与账户一致性

详情滑杆和沉浸爱心使用同一个显式赋值接口 `artworkRating.set`，接受 `1 | 2 | 3 | 4 | null`；读取使用 `artworkRating.get`。接口身份来自 Session，`expectedUserId` 仅拒绝账户切换后的过期请求。服务核验作品为活动、未删除状态，并在作品锁和事务内更新；相同值提交幂等。

保存控制器和队列独立于浮层与单个媒体项的挂载，关闭浮层不会丢弃已经提交的保存。连续操作串行发送，尚未发送的目标只保留最新值；旧响应不覆盖新预览。读取及保存中在滑块内部显示加载反馈，保存成功在同一位置显示 280ms 勾选动画，结束 200ms 后自动关闭卡片；减少动态效果时直接显示勾选并在 200ms 后关闭。再次操作会取消待执行的自动关闭，失败时保持打开。最终失败恢复最后成功值，仅此时在面板内显示错误和重试操作；状态变化同时供辅助技术朗读。

缓存、队列和响应按账户与作品隔离，切换身份后旧响应不能影响新账户。确认结果联动详情、沉浸 feed 和喜欢集合；新增喜欢的位置由服务端排序决定，动态候选沿用现有分页规则。`likedOnly` URL、快捷筛选和游标字段保持兼容。

## 存储、生命周期与升级

沿用 `ArtworkLike` 存放唯一评分状态，原表名为兼容存储名称；不要再把任意关联记录解释为喜欢。数据库数值约束、计数触发器和迁移实现的权威说明见[数据库设计](../../packages/pixishelf-db/prisma/database-design.md#作品评分与喜欢计数-artworklikelevelartworklikecount)。

历史喜欢迁移为喜欢档，保留记录 ID、账户归属、创建和更新时间；历史未喜欢作品保持无记录。来源刷新、同作品内媒体替换及排序保留评分；回收期间保留，恢复后可见；永久删除作品或账户时级联清除。

升级使用正式 migration 和 generate/deploy，在隔离数据库验证旧数据后，按[备份恢复基线](../operations/backup-and-recovery.md#发布前一致性检查点)建立匹配程序与数据的一致检查点，停旧写入者并整体发布前后端。一般档开始写入后，旧应用的“有记录即喜欢”语义已不兼容；回退版本必须理解评分阈值并保留数据，不能删除一般档、评分列或把所有档位改回喜欢来掩盖差异。需要恢复不兼容旧程序时使用匹配检查点，按恢复流程评估之后新增数据的损失。

## 验收与证据

验收覆盖全部档位转换、历史迁移与时间戳保留、约束及级联删除、喜欢集合与计数一致性；同时覆盖账户隔离、非活动作品拒绝、重复提交、两入口同步、快速改档、失败重试、关闭后保存和迟到响应。喜欢分页另覆盖一般排除、高档包含及降档后的续页。

UI 检查桌面、窄屏、横屏、安全区域、键盘和焦点恢复，覆盖单图、单视频、未读为空、自动浏览、媒体预览与继续阅读提示；核验紧凑布局、滑块内加载与短时成功反馈、仅失败时显示重试，以及背景／Escape 关闭。浏览器验证使用 `entry=direct`。执行环境、实际结果、恢复依据及未覆盖项见[2026-10-22 评分验证记录](../records/features/artwork-rating.md)。
