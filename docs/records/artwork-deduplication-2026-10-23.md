### 独立设计审查

审查者：`dedup_stage0_review`，未参与文档实现。逐项修复并复审了：

- 恢复与永久清理使用不同前置条件；恢复不依赖保留者可用，清理必须重新确认保留者。
- 预览构建明确 FAILED / STALE；恢复处理依据原动作分流，部分清理只能继续原授权范围。
- 候选筛选前检查全部登记文件属性，不能用旧大小跳过可能变化的作品。
- 上传没有 Image 时也有持久路径保护；扫描前后目录版本匹配，不能过滤写入中文件后发布删除差异。
- 上传者以自身声明版本提交；不同路径可独立完成，目录范围声明与内部路径冲突。
- 新路径上传完成到成员登记之间保留声明和 receipt；替换内各文件独立检查点，未选中或失败残留先核验处置再解除目录保护。
- 永久清理确认体现适用备份检查点；界面不把输入该标识当作自动验证备份。

最终结论：阶段 0 静态审查通过，无剩余阻塞发现。仅描述设计语义，不作为实现正确性证据。

- Escape 关闭并恢复触发按钮焦点。

第二轮结论：修复复测通过，可进入阶段 1。未重复第一轮全部业务场景。截图已在浏览器 agent 的 CUA 工具输出展示；该工具没有文档化的图片落盘接口，因此本记录没有附加持久截图文件，也不声称已经保存。
