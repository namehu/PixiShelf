# 白边与轻裁剪：单轮改进

本轮开始先提交已验收的两批：`aa7262f2`（56 个文件，完整包含）和 `737c351b`（5 个文件，首轮离线视觉实验）。提交前核对开工快照，保留全部既有内容；第一份提交使用当时的设计草案快照，第二份才记录视觉实验更新，没有覆盖工作区文件。新实验基线为 `737c351b`，开始时工作区干净。

### 全候选观察发现的误配

预设 18 对负例之外，主 agent 从候选明细发现两个模板查询多匹配了一项。实施 agent 只读取已有特征缓存核对，确认 `fresh-03-template-0` 与 `fresh-09-template-0` 发生误配：两者是独立生成的随机主体、共享框架，属于已知负例，计 **1 个无向图对、2 次有向查询**。旧方案未产生该匹配。

误配使用一侧 5% 裁剪视图和另一侧原图；整图距离恰好为 12，局部一致区域为 0，走原有整图阈值分支。增加视图同时增加了偶然相似的机会。固定负例的 0/18 只能描述指定的那 18 对，**不能概括为完整检索零误配**；本轮也没有全面人工标注真实图间关系，不能给出生产误报率。

这项补充仅分析已生成的缓存，未重读图片、未重新解码、未重跑完整评估。runner 增加匿名匹配目标 ID 输出，便于后续审查；报告的 `additionalObservations` 保留补充证据。没有为了让结果变好而修改参数或过滤掉误配。

### 缓存与代价

新图副本共 6,807,747 字节，生成变体阶段另耗约 1.92 秒，其 I/O 不计入下表。每轮 153 个文件包括原图和变体，v1/v2 对照分别读取一次，不是整个实验只读取一次。

| 轮次              | 命中/153              | 图像缓冲读取 | 压缩输入解码次数 | 本轮耗时   |
| ----------------- | --------------------- | ------------ | ---------------- | ---------- |
| v1 冷缓存         | 0                     | 51,225,537 B | 153              | 12.75 秒   |
| v2 旧版本升级     | 0，153 个旧条目被拒绝 | 51,225,537 B | 306              | 14.42 秒   |
| v2 持久缓存载入后 | 153                   | 0 B          | 0                | 4.14 毫秒  |
| v2 修改一张变体后 | 152                   | 200 B        | 2                | 82.99 毫秒 |

v2 保留原始 v1 特征路径并生成 RGB 预览，因此每个压缩输入解码两次，共享已读取的内容缓冲；后续 raw 视图缩放不计为再次解码压缩输入。热轮计时包含缓存写回，不包含缓存 JSON 读取/解析；0 B 只表示图像内容缓冲读取，不是无属性或缓存 I/O。旧版本必须失效，避免混用缺少视图的缓存。

| 18 次小样本查询  | v1        | v2         |
| ---------------- | --------- | ---------- |
| posting 访问合计 | 2,933     | 11,364     |
| 候选页合计       | 372       | 969        |
| 视图对核对合计   | 372       | 9,315      |
| 评估耗时         | 5.41 毫秒 | 34.34 毫秒 |

全部查询没有耗尽预算，单次 posting 访问最多 1,091。汇总包含 self，同一候选可出现在不同查询中，不是唯一图片对总数。更多视图还会增加候选数量，不能把“每对图片最多 16 视图对”当作整体开销至多 16 倍。153 个文件的哈希净载荷从 12,240 B 增至 38,880 B，最大四视图；不包括 JS 对象、JSON、信息量元数据与索引。

v1/v2 最大单个特征子进程 RSS 分别约 64.73/74.07 MB；父进程历史 RSS 峰值约 180.06 MB，包含准备阶段，不是父子进程同时峰值之和。单图实验限制保持 32 MiB、4,000 万像素、子进程 10 秒、V8 heap 128 MiB；heap 不限制 native RSS。

本轮没有运行 50 万特征或图库实验，不把这些毫秒数外推为全图库吞吐。四视图最多 320 B 哈希/图，50 万图仅哈希净载荷理论上就可能达到 160 MB；索引、数据库和整个进程的内存仍未验证。
