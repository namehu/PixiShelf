# Android 核心阅读页面迁移验证

本记录对应主工作区分支 `codex/android-local-validation`、Flutter `0.3.0+6`。目标是在功能和阅读语义尽量一致的条件下，对比 H5 与 Android 操作体验。现行行为见[Android 规格](../../features/android-app.md)，不把本地通过视为生产发布或性能胜过 H5。

## 范围与保护边界

- 图库封面进入纵向作品详情；详情内适配预览限制为当前作品，独立沉浸浏览仍横向切媒体、纵向切作品。
- 接入详情元数据、评分、单图书签／喜欢、冻结未读集合、手动已读、共享堆叠规则、作者邻作、来源和系列前后篇。完善自动浏览、分段进度、视频手势与导航。
- 新增移动 transport 复用领域服务；没有数据库迁移、Worker、网页页面、tRPC 或 Cookie 登录行为修改。F5 服务未重启，生产构建在不含本地环境文件的临时源码副本执行。
- 保留媒体 Future 清理和 codec 生命周期修复；新增有限上一帧过渡、平滑缩放、原生页面转场。原件仍通过受保护接口按需读取，不建立离线图库。
- 全屏预览只记录实际观看的单个媒体，不携带堆叠授予。只有详情堆叠卡片使用共享组证据。手动已读不制造访问事实。

## 自动化与模拟器证据

环境：macOS、Flutter 3.27.3／Dart 3.6.1，Android API 35 专用模拟器，软件图形使用 `--no-enable-impeller`；所有原生 fixture 使用合成媒体，不连接真实业务实例。

首次网页全量运行与构建并行时，既有 `archive-discovery-batch-sources` 一个用例超过 5 秒；单独复跑该文件 6 项通过。随后按相同单元范围、`--maxWorkers=2` 重跑全部通过。跳过项依赖未配置的隔离 PostgreSQL 等条件，不计为通过。未降低断言或增加测试超时。

首次原生连续翻页暴露出视觉转场等待 180ms 阅读稳定计时的问题。改为首帧渲染后启动转场，阅读计时独立；新增回归验证首帧回调不产生提前阅读。原生测试按页码、就绪及转场状态作有上限等待，截图另等待可见项实际解码，避免将占位当作完成。

独立界面检查发现页码／更多操作下缘与 48dp 进度触控区重叠；信息栏移到安全区上方 56dp，保留 8dp 间距，视频控件随之预留空间。追加按钮下缘实际点击回归，相关 3 项测试通过；原生往返重跑通过，复拍后的独立判定为该项已解决。合成截图仅证明布局与返回位置，不证明真实内容下的性能、发热或所有字体／方向组合。

## 限制与复核

关键帧目前提供时间点定位，没有派生缩略图；高级日期／音轨／创建类型筛选、快捷筛选管理和完整系列列表未全部迁移。复杂管理、离线下载、iOS 和鸿蒙不在本轮范围。

正常 USB APK 使用默认 Impeller，仍为 Debug／开发签名，服务地址是 ADB reverse 的 `http://127.0.0.1:5430`。Release／Profile 的 HTTPS 边界不变。功能联调结果不能用作性能比较；尚未完成同网络条件下优化构建的长期基准。

0.3.0 正常入口 APK 为 `app-arm64-v8a-debug.apk`，87,331,510 bytes，SHA-256 `d960ad2519c2cd07c594d3846b318e18d0241e4b3d2fd12b8acccc448f1b265c`。该版实际手机确认登录保留、详情首图加载、100 项作品选第 31 项、预览横向切到第 34 项以及回图库位置恢复。随后用户指出列表样式与入口不符合对比要求，因此这些功能通过不代表外观或交互已获用户验收。

## 0.3.1 列表与沉浸布局纠正

用户要求直接可对比的列表及点开上下切换。后续版本恢复 H5 的白底、单行紧凑工具栏、卡片排版和同账户 card/minimal 偏好；封面直接进入跨作品沉浸、标题进入详情。此入口是本次明确要求的 Android 取舍，不误记为 H5 当前默认入口。沉浸顶部仅保留圆形返回／筛选，页码移到右上，底部作者／标题缩为 H5 字号行高，喜欢／更多横排，设置进入更多菜单。Next 仅追加已认证只读展示字段，无数据库／Worker／H5 页面改动。

随后按用户指正删除详情每张图片下的序号／状态／操作栏，完整模式取消左右和底部间距，恢复满宽连续拼接。单图操作保留在长按菜单；堆叠模式保留组卡导航。未把这种视觉修正扩展为媒体加载或阅读事件算法改写。

0.3.1 自动化验证：Flutter 50 项全部通过，包内 `flutter analyze` 无问题；移动展示字段 26 项聚焦测试通过、定向 lint 和 TypeScript 检查通过；文档检查通过。图库回归包括封面打开跨作品阅读器并上滑切到下一作品、minimal 模式 2dp 间距、长按详情菜单及原有定位返回。新版原生脚本已更新入口，本轮不重复将旧模拟器结果当作新版实机证据。

正常入口 APK 版本 `0.3.1+7`，87,341,257 bytes，SHA-256 `909de74baa73bf6fe0fa210181022eb6ffe518fb6736ef0ddec717e875797278`。构建保持 USB Debug 开关与原账户数据，测试入口未安装到实体手机。
