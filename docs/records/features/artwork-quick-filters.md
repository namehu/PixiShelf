## 快捷筛选验证记录

### 2026-10-14 本地验收记录

- 主应用 lint、typecheck 和提升权限的 production build 通过，路径大小写检查无命中。
- 全量单元测试首轮 2578 项通过、175 项按环境约定跳过；5 项失败均为沙箱禁止本机监听或 tsx IPC。对应两个测试文件提升权限复测 35 项全部通过。随后增加的账户切换/卸载迟到响应及导航命令消费回归测试单独通过。
- 独立 PostgreSQL 15 临时容器通过正式迁移部署，5 项快捷筛选事务测试全部通过，容器及合成数据验收后移除；没有连接或修改现有收藏库。
- 真实浏览器检查 1440×1000 桌面、390×844 手机视口、深色主题、10 项导航、长名称、管理跳转、保存不应用、应用后的 URL 和隐私文本模糊。修正了手机菜单锚点覆盖底栏及导航临时参数残留。深色主题通过临时样式测试条件验证，测试条件已撤回；未新增全局主题功能。
- 悬浮和触摸长按的时间、位移取消、释放点击抑制由可控计时器组件测试覆盖；本次没有连接真实触屏设备。生产部署和真实手机触摸验收仍须在发布时确认。

### 2026-10-15 Android 导航长按修复

- 手机作品入口改用原生按钮承载短按跳转和长按菜单，移除可被浏览器识别为链接预览的地址；保持原有视觉、500ms 阈值、位移与多指取消以及释放点击抑制。
- 导航、页头及共享长按的 26 项聚焦测试通过，覆盖原生 contextmenu 在计时前后出现、释放不导航、取消后可再次短按，以及键盘打开和 Escape 焦点恢复。
- 主应用 lint、typecheck、提升权限的 test 和 build 通过；全量 2609 项通过、175 项按环境约定跳过，路径大小写检查无命中。
- 本次未连接真实 Android 设备，组件事件测试不等同于原生浏览器菜单的真机验收。
