## 用户浏览器／手机回归

先重启本地 Next.js 服务，使运行进程加载新 Prisma Client；手机用原先可访问的电脑地址及端口 5430，并在入口加 `entry=direct`。

1. 打开多图作品，长按某张图添加书签，再喜欢同一张图；分别取消其中一个，另一个应保留，刷新后状态不变。
2. 打开适配预览、原图预览，核对顶部两按钮；进入沉浸阅读，在“更多 → 当前图片”操作，确认原有作品爱心／评分不受影响。
3. 手机“更多 → 我的图片”切换书签／喜欢标签，点击某张靠后的图片，检查直接定位到该图；开启堆叠模式再试一次。
4. 给动图和视频添加标记；视频详情从“图片操作”进入，长按倍速仍应可用，视频收藏整段内容。
5. 在窄屏、横屏和隐私模式下检查按钮遮挡、点击范围、缩略图及作品名遮蔽。连续快速点击并刷新，确认最终状态一致。

删除／替换失效、回收恢复、跨账户及超过 24 项分页已有自动测试；如果需要额外浏览器验收，可使用开发测试作品验证，不能据此声称已完成真机测试。
