# 归档交互与自动入队

本方案经用户逐项确认，已于 2026-09-09 完成实施与验证。本文保留决策和验收记录，当前行为以 [归档收件与下载](../features/archive-intake.md) 为准。

## 用户流程

- PC 保留紧凑表格，移动端采用精简卡片。默认显示标题、状态、来源、图片数量和简短时间；仅运行态显示进度，失败态显示可操作的错误摘要。质量、重试次数、批次、完整时间和媒体预览移入任务详情。
- 可用本地作品的标题进入作品详情，否则打开任务详情。独立“原站”入口在新标签页打开该次归档的规范化画廊页，不切换到远端新版。
- 添加 URL 和人工勾选发现结果时，默认“解析并归档”，可选择“仅解析”；按次统一选择画质，默认原图。来源扫描仍需人工触发和勾选。
- 自动模式下：新作品解析成功后入队；已有作品有变化时等待人工确认；未变化直接跳过；已有活动任务则关联且保留其画质。版本关系只作提示，不自动追新版。
- 原图不可用继续暂停，不静默降为展示图；普通网络错误沿用现有重试规则。
- 历史收件保持手动。新提交持久保存模式和画质，重试/修正继承该意图；关闭页面不影响后台衔接，已取消项不会自行恢复。

## 契约与一致性

- 新提交接口接受 `downloadMode: AUTO | MANUAL` 和 `quality: ORIGINAL | DISPLAY`；UI 显式提交默认 AUTO/ORIGINAL，缺省模式的旧调用保持 MANUAL。
- 数据库新增字段默认 MANUAL，既有记录不被自动激活。使用正式 migration，不执行 `db:push`。
- 解析仍由 resolver lane 执行，下载由 writer lane 执行；后台完成解析与入队之间必须可恢复，幂等复用已有任务。
- 自动入队不得依赖浏览器轮询回调或 Next.js 进程内异步任务。提交幂等指纹包含模式和画质；取消、身份去重、发布/回收并发以及租约 fence 继续生效。
- 原站链接使用受会话保护的跳转入口，从数据库读取并验证来源 URL；列表保持脱敏，错误/事件不暴露 gallery token 或凭据，标题和来源继续遵循隐私显示。

## 验收

- 桌面表格和窄屏卡片信息一致，长标题不会挤出操作；已完成项不再展示 100% 进度条和重复成功文案。
- 标题导航遵守作品生命周期，原站入口只能重定向到受支持来源；未登录不能读取或跳转私有任务信息。
- URL/发现来源两入口均提交模式和画质；仅解析保持手动确认流程。
- 覆盖新建、更新、未变化、已有活动任务、重复提交、取消与恢复；自动入队与解析终态事务一致或具有等价的持久恢复保证。
- 验证迁移默认值与历史记录不自动启动，使用隔离数据库验证任务原子性和并发；完成相关单测、类型检查、主应用 lint/test/build 与 Worker 构建。

## 验证记录（2026-09-09）

- 主应用 lint、typecheck、生产 build 通过；全量单元测试 1,782 项通过、101 项因数据库环境门禁跳过。
- Worker 依赖链 typecheck、build 通过；全量测试 803 项通过、174 项因数据库环境门禁跳过。
- 隔离 PostgreSQL 分别完成解析与自动入队 17 项、收件服务 15 项、发现来源服务 11 项验证；迁移测试 2 项通过，覆盖历史记录保持 MANUAL。路由权限与兼容默认值测试 22 项通过。
- 两个独立空库均成功部署完整 77 个迁移。事务验证覆盖自动新建、更新待确认、未变化跳过、复用活动任务、取消与租约 fence，以及无效默认标签导致单项可重试失败而不终止 Worker。
- 浏览器使用合成数据检查 320px、390px 移动端与 1440px 桌面；无水平溢出，任务抽屉、作品标题导航和提交模式/画质持久化正常。原站入口通过链接语义、权限与 URL 白名单测试验证，未发起真实远端下载。
- 独立代码审查通过，无 P0/P1 阻塞项；新增主应用路径符合小写约定，差异空白检查通过。

## 恢复依据

本次开发不向生产库或现有收藏执行迁移、下载、替换或清理。迁移验证使用隔离 PostgreSQL。正式部署前遵循 `docs/operations/backup-and-recovery.md` 建立数据库、媒体与配置的一致性检查点，并同步升级 App/Worker。回滚时先停止提交并等待或取消活动任务，保留新增模式字段和已创建的任务，不用降级脚本删除任务或媒体；按检查点恢复时数据库与媒体必须成组恢复。
