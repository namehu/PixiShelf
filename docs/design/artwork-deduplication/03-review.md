# 结果审核与删除预览

检测、分页、建议、持久审核和只读 PREPARE 基础保留；本页将后续目标改为 DIRECT_DELETE。当前已验证范围与未完成项见[阶段三记录](../../records/artwork-deduplication-stage-3-integration-2026-10-24.md)、[规模记录](../../records/artwork-deduplication-prepare-scale-2026-10-24.md)及[暂停交接](../../records/artwork-deduplication-resume-pause-2026-10-24.md)。不能把旧 ISOLATION 预览或本文当作新删除已实现。实际授权、文件与故障规则唯一由[直接删除契约](./direct-delete.md)维护。

## 沿用的审核规则

`/admin/duplicates?artistId=…` 显示当前艺术家结果，不隐式全库检测；有活动检查时可查看上一份完整结果。组和组内成员分别分页，默认 20、上限 100，稳定游标限定 run/版本；列表仅有界预览，不载入全部成员。检测事实共享，审核按 Session 账户保存；切换账户清空选择/缓存，迟到响应按账户、run 和版本丢弃。

保留建议继续优先保护所有账户的评分和媒体书签/喜欢，包括失效标记：只有一部有手工整理记录时推荐保留它；多部有记录时需明确选择；其余按本账户最近真实阅读、最早入库和稳定 ID。普通阅读影响推荐但不使全部已读作品不可选。其他账户只显示“有其他账户整理记录”，不返回分数、标记内容/类型/数量、时间或阅读排序。

每组必须选一个 keeper，选择 keeper 不隐式选中删除组。全部建议由服务器覆盖当前冻结 run 的未加载页，跳过需人工选择和不具资格项，返回实际范围及原因。标题、来源、标签、系列、章节、人工顺序、归档历史和整理差异按需展开；相同原媒体不代表整份收藏数据可无损删除，整理不合并。

## 冻结预览调整

PREPARE 沿用 BACKGROUND_WRITER、稳定 operationId、分页表、reader、检查点和让行预算。它冻结选中组/keeper/copy、审核版本、根/来源/成员、精确文件及整理影响，不长期认领、不隐藏、不删除。新目的明确为 DIRECT_DELETE，旧 ISOLATION READY 必须重新准备，不能升级授权；新目的和实际删除均受独立关闭的能力门禁约束。

BUILDING 可离开页面并续查；READY 显示服务器范围及明确删除影响，STALE 移除确认按钮并引导重新准备，FAILED 保留范围/诊断并可重试。未知附件、共享路径、硬链接、符号链接、越界和未参加一致性验证的旧归档原件在预览阻断该作品；不强制忽略、不静默略过、不按父目录扩大。已确认范围后来出现阻断时使预览失效，不能悄悄删剩余部分。

最终预览只提供一次“永久删除 N 部副本”确认，包含不可恢复后果、文件和整理影响、外部同步/编辑停写声明；不用隔离区或第二次清理步骤。确认后 Worker 仍须认领双方、实际 drain，并对所选全部组 fresh 校验成功后才允许首删。正式 UI 在第三批接入，设计见[页面稿](./ui-design.md)。
