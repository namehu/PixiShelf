# 热检查：资料留内存，未变化直接复用

用户批准后开工。当前功能依据仍为[功能规格](../../features/artwork-deduplication.md)；本页保留本轮已实施的批准契约，结果见[本轮记录](../../records/artwork-deduplication-hot-run-reuse-2026-10-30.md)。

## 范围与基线

最新 main 为 `c8d1f380`（v0.55.2）；独立分支 `codex/dedup-hot-run-reuse`。生产艺术家 2812：7,905 原件，175.279 秒，1,076 次事务。已无原图读取、解码或视觉候选遍历，主要消耗在前置清单、作品指纹、关系与缓存特征整理。

只优先优化整批未变化的快速检查。有变化继续使用现有增量流程；不重写匹配算法，不改动图规则、四类关系、删除流程和 1 万原件上限。不增加表、服务或长期内存缓存，不操作生产。

## 资料与提交

- 作品、成员、文件属性、SHA、缓存身份和摘要，每页 500 条普通读取到任务内存；不预载原图及无需使用的视觉特征。
- 额外工作集预算 1 GiB；估算资料到 800 MiB 停止预载，释放已提交部分并回退分页。记录实际进程 RSS，任务预算不等于整个 Worker RSS。容器限额不自动修改。
- 单任务、单计算线程、属性核对并发 4。每批最多 500 原件、50 作品或约 1 秒处理时间，先到者收口，大作品跨批。
- 自动让行可保留只读资料；暂停、取消、结束或切换任务释放。内存仅加速，不是执行许可或恢复依据。
- 有效作品指纹直接复用，不再重读成员与 SHA 清单汇总；一次提交保存原件、完成作品、游标及计数。变化、缺缓存、FULL 继续重算。

## 整轮复用

原件核对后、关系和特征准备前判断：同一艺术家、同一作品与原件范围、检查选项一致，文件和缓存身份全部有效，算法／特征／关系版本兼容，历史运行完整完成。仅动图等明确未核对项允许复用；失败、中断、达到上限或 FULL 不允许。

符合时跳过包含／部分重复候选、视觉特征重整理和视觉检索。通过数据库内部批量复制分组、关系、图片证据及必要缓存明细到本次运行，避免应用搬运大型 JSON。每批最多 1,000 条明细，稳定业务 ID 和持久游标使重放幂等。按当前图片顺序生成位置，标题变化不重算。不能复制审核选择、删除确认或授权；完成结果不依赖历史运行保留。

历史依据在复制中失效时，清理本次未完成复用产物并回退普通路径，不能拼接不同历史来源。

## 安全与兼容契约

每次写事务一次批量核对执行权、作品归属、成员、来源、目录和写入状态；同事务内部避免重复查询。权限不跨事务，最终发布和删除前完整核验保留。结果、游标、计数原子提交，重启最多重做最后未提交批次。

用户开工后明确取消旧任务续跑兼容要求。扫描 Worker 仅注册 v9；升级前取消未完成旧扫描，之后重新发起。已完成旧记录和有效缓存保留，可用于 v9 复用；不增加历史任务转换或兼容层。整轮复用在已有 JSON 检查点使用新版本，记录历史来源、输入摘要、复制阶段、游标；仅新增放行扫描 v9 的数据库约束迁移，不增表、不改列、不清数据，不改变有效特征／文件缓存版本。约束继续允许历史版本记录，Worker 不再执行未完成旧扫描。既有共享函数内的历史路径不在本轮扩展成整套清理重构。页面接口不改，沿用阶段进度，禁止总体 99% 推算。

内部模块归属：核心执行器与 DB 批量入口由 Astra/high；契约、运行时计时、测量与文档由 Sol/xhigh；公共注册入口由主 agent 集成。独立审查 Sol/xhigh，桌面验收 Sol/medium。

## 计时与验收

汇总记录属性核对、指纹复用、关系复用、结果复制，事务获取／前置围栏／业务／后置围栏／提交收尾，批次数、复用数量、API 调用、事务数、固定等待及内存峰值。每 30 秒及阶段切换输出，不逐图打日志。API 不是 SQL；未知不记零，累计计数随提交去重，重放单列。

复用既有 2,000 图片／50 作品及同一份暖缓存备份，对 v0.55.2 与本轮各测一次，只有异常或影响结果的修复才补测。目标为热检墙钟减少至少 60%、事务减少至少 80%，结果一致且读取／解码／检索仍为零；未达到如实记录，不承诺 NAS 固定秒数。

专项覆盖未变化、修改／增删成员、缺缓存、FULL、混合媒体、顺序／标题变化、无重复，暂停／取消／失租约、目录变化、回滚、原件提交与结果复制期间的 Worker 重启、内存回退与释放。桌面覆盖进度、暂停续跑、刷新、对照和删除确认；实际删除仅隔离合成样本。

仅受影响专项、类型检查、必要构建、文档及图检查。完成审查与验收后提交暂停，不合并、发布或更新 NAS。
