# 去重页面设计

本文和[原型](./prototype.html)表达批准后的目标交互，不代表正式页面或 DIRECT_DELETE 已实现。正式 UI 作为第三批工作，门禁默认关闭；原型仅使用示例数据，不连接图库。后端的唯一授权和失败规则见[直接删除契约](./direct-delete.md)。

## 页面与信息层级

艺术家页“检查重复”进入 `/admin/duplicates?artistId=…&entry=direct`，无艺术家时先选择，不能隐式全库检测。标题、艺术家和主操作置于顶部；两标签为**检查结果 / 删除记录**。不再有隔离区、恢复、保留倒计时或 preparePurge。

结果以组和作品行为主，每组有唯一保留项 radio、独立删除组复选框、数量/来源/必要整理资格摘要及“查看差异”。默认每页 20 组，成员另分页；长组始终显示 keeper 摘要。四来源及混合组均可显示；来源只说明导入方式，不把 URL 副本引导进普通回收站。长标题换行，正文不铺内部版本、绝对路径、哈希或所有缩略图。

底部选择栏显示服务器实际组/副本范围，主操作为“预览删除”；不会因选 keeper 自动选删除组。桌面详情使用现有侧面板，手机使用全屏面板；保持原型现有色彩、字体、浅/深色、44px 触控和底部安全区。原型的状态选择器与“示例数据，不修改图库”提示不进入正式产品。

## 操作与状态

| 操作/状态               | 页面行为与接口                                                                                                                                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 开始/完整检查           | `start`；完整检查明确重新读取原件。未检查、加载、正常无重复、检查局部未完成、整次故障分开显示                                                                                                            |
| 检查进度/暂停/继续/取消 | `control`；离页继续，控制等待服务端结果，不把离页当取消。失败保留已有结果及重试入口                                                                                                                      |
| 保留建议/差异/跨页      | `saveReview`、`listGroups`；多份有整理记录需明确选择。切账户清选择，迟到响应不能串会话；他人只显示保护资格                                                                                               |
| 准备预览                | `prepareCleanup` 返回稳定 operationId/BUILDING，关闭后可续看。READY 显示服务端冻结范围、排除和阻断，不能让浏览器上传文件清单                                                                             |
| 预览过期/失败/阻断      | 清楚说明原因与重新准备/重试；无执行按钮。未知附件或未验证归档历史原件阻断作品，不以“其余可删”静默改变确认范围                                                                                            |
| 唯一删除确认            | 同一个面板列保留者、具体副本、原件/章节/来源和整理影响，说明“永久删除，无法恢复，整理记录不合并”，勾选不可恢复后果与外部同步/编辑停写声明后，“永久删除 N 部副本”可提交；不要求口令、备份表单或第二次确认 |
| 提交/网络超时           | `directDelete` 绑定版本、目的及幂等键；禁重复提交。超时查询同 operation，不新建删除；服务器决定 allowedActions                                                                                           |
| 认领/等待退出/内容复核  | 删除记录显示真实阶段，说明尚未开始删除。全所选范围校验成功才首删；此阶段可请求取消                                                                                                                       |
| 已开始删除              | 显示已删/待删文件数及当前状态；操作名改“请求停止”，说明在安全边界停下，已删文件无法撤销                                                                                                                  |
| 部分失败/安全边界停止   | 保留具体批次、已删/未删范围和脱敏原因；副本不可见。仅“复核并继续原删除”，重新验证 keeper 后续原范围；不显示恢复、换 keeper 或扩围入口                                                                    |
| 已完成                  | 删除记录按时间/数量/状态列批次，详情列原冻结范围、结果、必要诊断及来源抑制。不把记录过期等同删除墓碑                                                                                                     |
| 允许重新导入            | 完成条目详情的次级入口，列可解除的真实来源；单独说明只允许未来新输入，不恢复文件、不使旧任务有效。LOCAL_CREATED 无可发现来源时不显示伪造来源行                                                           |

一次确认是一次用户删除授权。失败后“继续原删除”仅核对并使用原授权，不生成新的删除计划或再加永久清理确认；若版本/范围已失效，必须重新准备并完整展示新影响。允许重新导入是独立来源意图，不属于第二次删除确认。

## 整理影响与隐私

当前账户可看自己的评分、有效/失效媒体标记和阅读影响；其他账户只能显示“有其他账户整理记录”，不暴露其账户、分数、标记类型/数量、时间或私有阅读顺序。相同原媒体不等于所有收藏数据相同，标题、来源、章节、标签、系列等差异按需展开。整理记录随对应副本业务删除，不自动迁给 keeper。

展示精度：标题、来源、创建时间及文件范围取操作已保存的快照；评分、媒体标记和阅读仅展示当前账户的实时记录，并注明执行前会复核。删除后显示“已随副本删除”，不以零值代替未保存的历史个人明细。标签、系列、派生指针及整理影响由冻结签名保护，页面说明随副本删除且不合并；未持久化的明细不得声称为冻结快照。

文件摘要只展示必要相对文件名/角色，不泄漏绝对路径、根 marker、inode、原始哈希、租约或执行 token。无可读封面保留占位，不在 HTTP 中重编码。网络/权限错误与空结果分开；账户变化清空确认和操作缓存。

## 交互验收

沿用 D3-B01/B02 的分页、焦点、空/错/过期和桌面手机要求，新增 DD-B01–03：一次确认须绑定服务器范围及停写声明；取消与删除后停止措辞准确；部分失败只续原范围；四来源混合组、未知附件、旧预览不兼容、重复提交及会话切换均可理解。Dialog 具可访问名称、Esc/关闭、Tab 围栏和关闭后焦点归还；tab 支持方向键；状态通过 live region 宣读；44px 控件、长标题和安全区在窄屏无横向溢出。

最终浏览器按总计划指定 GPT-6.1 Sol / medium，使用隔离环境和 `entry=direct`，集中在第三批；原型可点不替代数据库、文件系统和崩溃测试。
